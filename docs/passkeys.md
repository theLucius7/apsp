# 管理员与代理用户 Passkey

Passkey 使用设备指纹、面容、PIN 或支持用户验证的安全密钥完成身份验证，私钥留在认证器。管理员保留原有密码/TOTP 登录；代理用户入口属于 sing-box 插件，只能查看自己的订阅、累计上传/下载和管理自己的密钥。

## 部署条件

将 `APSP_PUBLIC_URL` 设置为实际使用的 HTTPS 域名，例如 `https://panel.example.com`，并始终通过这个地址访问。本地开发允许 `http://localhost:8080`。HTTP 公网地址和 IP 字面地址会禁用 Passkey 并提示原因，原密码入口仍可用。浏览器必须支持 WebAuthn，并能够进行设备解锁或安全密钥用户验证。

服务端只接受配置地址对应的 Origin，不通过 `Host`、`Forwarded` 或 `X-Forwarded-*` 扩大认证范围。反向代理应保留浏览器的 Origin，并正确提供 HTTPS。改变域名/RP ID 后，原 Passkey 不能直接迁移：管理员使用原密码/TOTP 重新绑定，代理用户由管理员重新生成开通链接。端口受精确 Origin 限制，默认端口按 URL 标准规范化。

容器已声明 OpenSSL 构建和运行库。源码构建面板需 OpenSSL 开发库及 `pkg-config`；Debian/Ubuntu 使用 `libssl-dev pkg-config`，容器运行环境使用 `libssl3`。Agent 不新增该依赖。首次启动自动执行迁移 `0039_passkeys.sql`，只新增认证与插件账户映射表，不改原用户 ID、订阅令牌或用量账本；升级前沿用现有数据库备份流程。

## 管理员

1. 使用密码登录，在「系统管理员」的「Passkey 通行密钥」中添加密钥。
2. 填写可辨识的名称，重新输入管理员密码；已启用二步验证时还需尚未使用的验证码。
3. 在浏览器提示中选择设备或安全密钥并完成验证。之后登录页可直接点击「使用 Passkey 登录」。

每个账户最多十把密钥，列表显示绑定及最近使用时间。删除密钥需要重新验证密码/TOTP，并退出其他管理员会话、取消待完成挑战。管理员可删除最后一把密钥，因为密码入口保留。建议保留原密码和 TOTP 恢复途径；已绑定 Passkey 是独立登录方式，不再次要求输入 TOTP。

## 代理用户

在 sing-box「代理用户」选择用户，在「用户 Passkey 入口」中生成开通链接。此操作也需要管理员重新验证密码和已启用的 TOTP。将完整链接私下交给该用户；链接十五分钟有效且只能开通一次，完整秘密仅生成时显示，重新生成使旧链接失效。

用户打开链接，命名并绑定自己的 Passkey，即可登录专属页面。页面移除地址栏中的开通秘密，并提供可收藏的登录地址；这个地址中的账户 UUID 只是标识，不能替代 Passkey。旧订阅链接/令牌不能用于开通、登录或恢复。

用户可复制或下载自己的 sing-box 订阅、查看累计代理流量，并添加备用密钥。密钥管理先重新验证现有 Passkey，再添加或删除；服务端要求验证时间在五分钟内，且始终保留至少一把密钥。删除密钥会退出其他用户会话。没有可用节点或套餐不允许使用时，订阅仍遵循原有授权/配额规则。

用户丢失全部密钥时，管理员点击「重置用户 Passkey」并明确确认。重置立即撤销该用户全部密钥、会话和未完成挑战，生成新的开通链接；原订阅、授权和历史用量保持不变。删除代理用户同时删除其 Passkey 和会话。

## 会话与限制

- 管理员使用 `apsp_session`；代理用户使用独立的 `apsp_proxy_session`。两者都是 HttpOnly、SameSite=Strict，HTTPS 下带 Secure，最长二十四小时；不会互相提升权限。
- 注册和登录挑战最多五分钟，存于 PostgreSQL，绑定账户、用途、发起会话/邀请和浏览器 Cookie。验证请求一次性消费；过期、重放、错误来源和错误账户均拒绝。服务重启不丢失挑战，但不会延长有效期。
- 每个账户最多八个待完成挑战，全局最多二百五十六个；代理用户最多十个会话。注册/登录两阶段、密钥删除和开通操作共用既有认证限速：每实际连接 IP 每分钟八次、全局六十四次、并发四个；代理后按代理地址计数。遇到 429 请稍后重试。
- 列表不返回凭据公钥材料、设备签名或开通秘密；数据库保存凭据公钥/验证状态及开通令牌摘要，仍须保护数据库和备份。更换设备是否可同步密钥由设备/密码管理器决定。

设计依据见 [ADR 0059](adr/0059-passkeys-and-proxy-user-access.md)，接口见 [HTTP API](api.md)。本地验证使用 Chromium 虚拟认证器，不代表真实 Touch ID、Windows Hello、手机跨设备扫码或实际反向代理环境已经验收。CI 按仓库安排继续暂停。
