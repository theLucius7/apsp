- 学习静态资料与实时采样分开刷新、暂停隐藏页、按服务器身份过滤实时数据、没有新采样就不补造点的做法。

## 数据语义与刷新节奏

支持新版 DTO 的服务器展示每 3 秒读取 `/api/dashboard/live`，每 30 秒读取完整服务器资料，拨测总览每 15 秒读取。只有轻量接口返回的当前可见 ID 可以更新已有卡片；新 ID 触发完整读取。公开范围变化、被隐藏或撤销访问时清理旧资料并中止在途请求，降级为公开访问后重新验证访问范围。公开访问没有成本、币种操作、设备秘密、主机名和拨测目标地址。

实时曲线只追加实际接收且晚于持久历史末尾的采样点，单独标明“实时采样”；这不是持久 ACK。详情分别显示设备采样时间、实时状态接收时间、最近已存采样时间，以及实际配置的采集、上报和历史写入间隔。旧 DTO 继续使用原 `/metrics` 历史及 5 秒状态刷新。

资源历史提供 15 分钟、1 小时、2 小时、24 小时、7 天、30 天窗口。以服务端返回的真实 `bucket_ms` 展示粒度，刷新间隔为 `max(15 秒, min(5 分钟, bucket_ms))`。图线表示均值，色带和单点竖线表示最小至最大值；指针或键盘可查看每项指标有效样本数、总样本数、实际采样范围、聚合窗口和部分历史标记。缺少指标或整个窗口时保持空缺，网卡计数器不参加平均、不转成周期流量或费用。图形简化同时保留聚合极值。

每个请求绑定页面路径、服务器、权限范围和所选窗口。页面隐藏、卸载、切换或暂停会取消相关请求，晚到结果不能覆盖新窗口或恢复已隐藏数据。12 秒超时保留旧快照并明确提示；401、403、404 清除受限数据。页面恢复可见时重新读取。

## 费用和汇率

显示币种默认 CNY，仅将币种偏好存到本地浏览器。折算使用面板每日真实报价：`原金额 / 原币种每 CNY 报价 × 目标币种每 CNY 报价`。同币种直接显示原额；缺少必要汇率或未填写价格时保留未知，不加入折算总计。常用选项包括 CNY、USD、EUR、HKD、JPY、GBP、SGD、CAD、AUD、CHF、KRW、RUB、VND，也可选择来源实际支持的其他币种。

管理员可见所填费用合计、每 30 天折算和已知账单周期、到期日的本周期剩余估算。一次性费用不混入周期成本。剩余值只是按周期与到期日线性折算的参考，不代表退款、实际付款或供应商账单。汇率显示来源链接、数据日期、获取时间和过期状态；具体资产的换算日期取涉及币种的较早有效日期。失败保留真实旧报价，没有内置默认外币价格。管理员手动更新走受限 POST，普通读取只读缓存。

- 既有 `server-display.mjs`、`dashboard.mjs`、`server-assets.mjs` 继续验证旧 DTO、原始历史、筛选表格、主题、键盘、网络错误及资产展示兼容。

浏览器夹具仅验证前端与 API 契约，不等于真实 Agent 常驻、多设备长时间上报、生产历史迁移或外部通知渠道验收。CI 暂停；最终构建及验证结果由主任务统一记录。
