# ADR 0036：服务器资产配置与账单周期网卡用量

状态：已接受。

## 背景

用户在完成新增与接入流程后，明确要求一起补齐 NodeFlare 表单中的地区、标签、成本到期和流量额度。按 ADR 0023 归入服务器管理，不改变代理用户、订阅或代理账本。

## 决策

- 服务器保存独立资产配置，包含地区、展示分组、标签、展示隐藏、金额、币种、以天为单位的费用周期、到期时间、日期自动顺延、流量额度、上下行统计口径、月重置日与网卡选择。旧服务器和仅名称请求使用默认值；创建、编辑保持事务一致。
- 金额用最多两位小数的十进制字符串保存，未填写与免费分开；字节额度及汇总也使用十进制字符串，避免浏览器整数精度损失。币种不自动换算。自动顺延只维护到期记录，不代供应商扣款或承诺完成续费。
- 月重置日使用 UTC，短月取该月最后一天。日期计算使用现有 PostgreSQL 日历功能，无新增时间依赖。费用周期与流量重置周期分别设置，不复用代理计量 epoch。
- 使用带采样时间的原有遥测维护逐网卡检查点与 UTC 按日累计，事务提交后才确认。按采样时间处理同批数据；重放和晚到的旧数据不重复累加。首个计数只建立基线，不把启动以来的全部计数当成本期流量；新网卡、缺失字段、重启和计数回退均明确处理。
- 差值归入后一个采样所在 UTC 日，跨日边界与长时间缺失会影响周期归属；发生断档或重置保留“不完整”标记。网卡用量是观测值，不替代供应商账单。旧的无采样时间消息继续展示系统指标，不用于账单日计算。面板升级之前和检查点丢失期间的用量不伪造补齐。
- 默认统计所有上报网卡，允许以 `*` 匹配、`!` 排除；可指定出口网卡避免回环和虚拟网卡重复统计。原始逐网卡日记录保留，调整重置日、额度、口径或选择网卡不会删除历史。
- 流量超过额度、服务器到期均作为展示状态，不自动停止服务、修改网络策略或影响代理授权。

## 验证边界

覆盖迁移默认值、鉴权、事务回滚、编辑保留、金额与大整数、UTC/月末/闰年、日期顺延、重放与乱序、计数重置、缺失采样、网卡过滤、周期归集和桌面/手机操作。实机流量与供应商账单核对单独验收；不把本地夹具或源码合入视为生产验收，远端 CI 按现有安排继续暂停。
