# ADR 0076：节点库、来源预览与外部订阅授权

- 状态：作者原输入已实现并记录本地验证；本聊天主线整合输入正在集中补修，冻结后统一验证。正式部署与真实来源验收待单独执行。按人分配外部节点已由 [ADR 0112](0112-group-only-access.md) 删除。
- 日期：2026-10-03。

## 背景与授权

用户要求整体参考 [miaomiaowu](https://github.com/iluobei/miaomiaowu/tree/be1198012768efd0a03d0cc20bd946e47d884050) 的节点管理，明确继续使用 sing-box，并确认外部节点独立管理、可直接分配给代理用户及生成订阅。参考其节点库、导入选点、标签、批量改名、排序和来源更新体验，独立实现，不搬入另一个代理运行时。

## 决定

1. 统一节点目录投影受管直连、链路与已采用的外部节点。外部节点不伪造服务器、部署状态或本地流量；管理员目录接口仅返回安全投影，不开放匿名节点或授权列表。目录附加标签、备注和排序；外部别名独立于上游名称，刷新不覆盖本地管理信息。批量操作最多 200 项，以当前修订摘要比较并在同一事务中完成。
2. 导入先解析预览，再选择节点提交。预览私密内容在服务端有界暂存十分钟，不创建正式来源或节点；提交复用同一内容，不二次抓取。解析失败项明确列出，不能被静默当作成功。来源抓取继续使用已有 HTTPS、SSRF、大小和时间限制。
3. 来源解析与加入节点库分开。升级前节点迁移为已采用，以保留现有可见性，且不会自动授权用户。新来源、后续新发现默认未采用；预览提交所选节点才采用。取消采用与删除先检查授权及链路引用。删除墓碑不会随刷新自动复活，重新采用需显式操作。旧链路选择与冻结版本保持兼容。
4. 来源自动刷新开关独立于间隔，允许有界请求 User-Agent；显示来源报告的上传、下载、额度、到期、更新时间和同步差异。缺失或失败不把未知值当作零。上游流量仅供参考，不进入面板计量账本。
5. 外部授权独立持久化，绑定来源、身份代次和版本，支持跟随同一节点或固定版本。新授权及变更检查当前采用/启用/身份状态；取消、删除与批量管理使用共同业务锁。来源更换、归档、缺失、身份歧义或目录停用不再向后续订阅提供该节点，已下载提供方凭据无法由面板远程撤销。
6. sing-box 完整客户端配置组合已生效受管节点与有效外部授权，标签隔离且顺序确定。套餐的订阅准入仍适用；外部提供方流量和配额不能由本面板强制执行。旧无外部授权的分享链接行为保持，有外部节点时链接格式明确要求改用完整 JSON，禁止静默丢节点。

主线整合额外统一目录与旧实体修订、删除及损坏历史引用保护；采用操作必须同时核对当前管理修订号，明确零表示尚无元数据。预览与后台刷新共用四个许可，阻塞解析及其待持久化结果在整个请求期间持有许可。保存预览在拓扑锁外解析，在事务内重读全部私有字段、解析器和当前期限，拒绝漂移内容且不二次抓取。

## 边界与替代方案

不把外部节点塞入要求服务器归属的 `nodes` 表，也不生成假的用户独立密码；沿用外部不可变版本。拒绝参考项目部分先写正式节点再预览的流程，以及按名称跨来源合并身份。别名、标签、排序不改变计量、链路秘密隔离或设备配置版本。

本轮不引入 Mihomo 测速实例、Clash 订阅输出、多管理员或任意原始配置执行。代理连通性/吞吐测速若扩展，须复用共用诊断框架和既有实机门禁，不能把端点 TCP 响应标成代理可用。没有新增依赖、Agent 协议或上游运行时代码修改。

## 验证

覆盖预览无正式写入、选择提交与过期/重放、来源更新保留本地元数据、并发修订和批量回滚、外部身份/版本与授权失效、旧订阅兼容、确定性组合与秘密白名单。浏览器验证桌面/手机、筛选分页、选择范围、批量预览、导入和代理用户授权。隔离 PostgreSQL 和本地 sing-box 检查不代表真实机场可用或生产升级验收；远端 CI 按当前安排继续暂停。

节点目录的受管数值身份与外部身份沿用现有接口；主线有序 UUID 资源保留独立接口、生命周期和发布身份。两者不能因页面合并而互相替换。目录展示的排序或凭据授权不证明外部服务流量已由本平台计量。
