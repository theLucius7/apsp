# ADR 0060：DDNS 双栈配置入口

状态：已接受。

用户要求 DDNS 支持仅 IPv4、仅 IPv6、IPv4 和 IPv6 三种选择。沿用 ADR 0048/0056 中“一条规则管理一个地址家族”的执行模型，在新增表单提供双栈入口：填写一次配置和凭据，面板在一个数据库事务中创建同域名的 A 与 AAAA 两条规则。

新接口 `POST /api/plugins/ddns/rules/dual-stack` 复用原创建请求，返回 `rules` 数组；原单类型接口及已有规则不变。双栈占用两条规则容量，其中任一类型冲突、配置无效或总量超限时整体回滚，不留下半组。选择双栈不隐式接管已有单类型规则。

两条规则分别维护候选地址、成功地址、提供方记录 ID、错误与退避时间，可独立编辑、暂停或删除。某一家族缺少可用地址时保留远端记录，不阻塞另一家族；仍使用现有新鲜度、服务器退役保护、写入前核对和每提供方有限对账。前端说明双栈创建后分条管理，不暗示 DNS 提供方支持跨记录事务或两种地址同时全球生效。

采用此方案可以保持四家提供方和持久化历史兼容，不增加第二套同步状态机或更改迁移历史。开发验证使用本地数据库和模拟提供方，不修改真实 DNS，CI 继续暂停。

参考：[Cloudflare A/AAAA 记录说明](https://developers.cloudflare.com/dns/manage-dns-records/reference/dns-record-types/)。
