# ADR 0027：IP 查询入口适配与正式凭据

日期：2026-10-01。状态：采纳。本项对应 Issue #24，不包含共用诊断任务框架或节点自查工具的执行。

## 问题

既有请求实际均访问同一 check-place 聚合入口，其七种 database 是响应视图，不能称作七个独立数据源。正式接口的凭据、成功契约与执行位置也不能由聚合响应猜测。面板出口对流媒体的查询无法证明服务器出口解锁。

## 选择

在面板 IP 模块中注册真实入口，每个适配器负责固定请求、身份与字段契约。共用查询调度提供最多四个并发、40 秒批次截止、单请求 3 秒连接/6 秒总超时、64 KiB 响应限制和既有错误分类，不在各入口分别复制 40 秒预算。缓存继续使用 0008 的 IP/provider/database 键，无表名或 schema 迁移。

保留 `check-place` 作为一个明确标记的旧聚合入口，七种响应视图归属于该入口。新增 `abuseipdb-api` 正式接口，依据 [AbuseIPDB 官方 API v2 CHECK 文档](https://docs.abuseipdb.com/#check-endpoint)：固定 HTTPS GET `/api/v2/check`，`ipAddress` 使用 URL 编码，`maxAgeInDays=30`，通过 `Key` 请求头传凭据，并请求 JSON。不请求 verbose、用户报告或写入端点，不设置 UA、不重试、不跟随重定向。

`APSP_ABUSEIPDB_API_KEY` 只在面板启动时读取。缺失、空白或不适合作为请求头的值使该入口不可用，并返回不含凭据的中文原因；凭据不进入 URL、日志、序列化、数据库或前端。凭据只保存在不实现 Debug/Serialize 的适配器内，请求头标记 sensitive。固定生产 endpoint 不允许管理员传任意 URL；回环 URL 仅存在测试构造路径。

官方返回的目标 IP、公网标记和 IP 版本必须与本次查询一致；明确失败、错误或身份不匹配保持未知。只展示经验证的用途、国家代码、ISP、Tor 标记和 0–100 的原始滥用置信度，不把评分、白名单或缺失布尔推导为“干净”。`isWhitelisted` 可空且官方不建议用作行动依据，此项不展示它。聚合入口和正式 API 分别持久化，失败不覆盖各自历史；入口被禁用后，已有成功数据标为历史并显示不可用原因。没有凭据不是一次网络请求，不编造尝试时间。

GET IP 信息提供入口描述：类型、执行位置、启用状态、原因与响应视图。前端按真实入口计数，节点流媒体解锁保持未知。未注册或关闭入口的旧快照保留，但不能充当本次成功。

## IPQuality 节点自查边界

[固定提交 87397e2c3196ec796f5477c83343c2354df601ea 的许可证](https://github.com/xykt/IPQuality/blob/87397e2c3196ec796f5477c83343c2354df601ea/LICENSE) 为 AGPL-3.0；脚本版本标为 v2026-09-16。此次只读检查[固定源码](https://github.com/xykt/IPQuality/blob/87397e2c3196ec796f5477c83343c2354df601ea/ip.sh)，未执行或打包。原版在选项解析前生成随机 UA 并读取在线引用；`-n` 只跳过安装，`-p` 只跳过结果上传，统计请求仍会发送。它还使用在线 main 的 cookies/ISO/DNSBL/赞助资料、请求重试、较大的 DNSBL 并发和多种宿主依赖。仅传 flags 不能证明满足本次约束。

`ipquality-node` 注册为未启用，并明确需要受控修改版本。后续独立 PR 必须将 AGPL 源码/修改、许可证、依赖与引用资源纳入固定校验签名制品，移除 UA 改写、统计/上传、在线 main、无界并发和宿主依赖安装；在节点自己的出口执行，并用静态及真实网络请求夹具验证。未经该验收不开放执行或声称流媒体解锁，不能用面板出口结果替代。

## 替代与后果

不抓取网页 demo、不借用上游内置公共 token，也不伪造七个官方接口。未配置正式凭据时保留清楚的不可用原因，不用零分或 false 补全。没有新增 Rust 依赖；此入口适配层不替代后续共用诊断框架。真实账户权限、额度和官方网络可达性需要运营者配置凭据后独立验证，本项回环 fixture 不冒充真实外部服务验收。
