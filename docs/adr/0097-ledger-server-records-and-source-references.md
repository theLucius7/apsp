# ADR 0097：费用与续费并入服务器费用记录、退订提醒与机场订阅到期

- 状态：已实现；本地编译、静态检查、PostgreSQL 集成测试与浏览器夹具见 [PROGRESS](../../PROGRESS.md) 本轮记录，未在生产面板上操作。
- 日期：2026-10-25。
- 落实：[ADR 0087](0087-narrow-positioning-proxy-network.md) 决定 4 的剩余部分（项目来源中的机场订阅、沿用运维资产档案的记录与退订提醒）；接续 [ADR 0096](0096-costs-and-renewals-ledger.md)。
- 关联：[功能地图](../product-map.md)、[日常运维](../fleet-operations.md)、[自动化与恢复](../operations-recovery.md)、[ADR 0085](0085-rearchitecture-plugins-sources-chains.md)（宿主、插件与组装分层）。

## 背景

ADR 0096 让服务器按资产设置列入账本，但服务器的购买、续费、退款与退订记录仍在「运维工具 → 资产与生命周期 → 续费与年度成本」登记（金额要按最小货币单位手填、历史以原始 JSON 显示），退订提醒在「自动化与恢复」配置，机场订阅来源报告的到期也不在账本中。ADR 0087 要求这些都进入「费用与续费」，同一设置只有一个编辑位置。

## 决定

1. **服务器费用记录在账本中登记，数据与接口不变。** 服务器行新增「费用记录」：列出原有记录与各年实际支出，并按币种自身的小数位数（如日元无小数）输入金额后，调用原有的 `/api/servers/{id}/fleet/costs`。记录仍保存在 `fleet_cost_records`，带有效期的购买与续费照旧更新服务器到期日期，权限检查不变。资产与生命周期页只保留各年汇总和指向账本的链接。
2. **退订提醒移到账本的「退订提醒」分页。** 复用原有组件和 `/api/operations/cancellation-reminders`，已有设置、站内事件与投递记录不变；自动化与恢复页改为链接。
3. **付款记录。** 新分页汇总续费项目的确认续期付款和服务器费用记录，按原币显示并按年合计：购买与续费计入，退款为负，价格变化与退订不计入，与资产账本的年度汇总口径一致。服务器记录按调用者的服务器范围与读取权限过滤。
4. **机场订阅到期经宿主钩子提供。** 宿主的插件接口新增 `renewal_references`：插件报告带到期日的外部服务，宿主不认识具体插件。sing-box 插件返回未归档、报告了 `expire` 的订阅来源（`subscription-userinfo` 中的到期与流量），组装 crate 登记实现；费用插件只依赖宿主取得这些引用，两个插件之间仍不互相依赖。引用按各自声明的权限（订阅来源为 `proxy:read`）过滤，在续费项目页、续费日历、iCalendar 与 30 天内续费中显示，没有价格、不计入预计支出、也不会被续期。
5. **不改动已有配置。** 不新增或修改数据库表；订阅来源、节点、成员运营与 Nexus 兼容桥的数据和行为不变。

## 替代方案

- **费用插件直接查询订阅来源表：** 实现最简单，但让费用插件暗中依赖 sing-box 插件的表结构，违反插件之间不互相依赖的约束。
- **把服务器费用记录迁入 `expense_*` 表：** 会复制已有数据并要求改写到期联动与退订提醒的引用，风险高而收益小；保留原表、只统一编辑入口。

## 验证

`crates/panel/tests/expense_subscriptions.rs` 新增：服务器费用记录经原接口写入后出现在付款记录中，续费的有效期更新服务器到期；订阅来源报告的到期出现在引用列表和 30 天内续费中，归档来源不显示，引用不计入合计。`web/tests/expense-ledger.test.ts` 覆盖币种小数位换算；`web/tests/member-commerce.mjs` 在 1440/390/320 宽度下覆盖服务器费用记录对话框（12.5 美元按 1250 最小单位提交）、机场订阅、付款记录与退订提醒分页。
