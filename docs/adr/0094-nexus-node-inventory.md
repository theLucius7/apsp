# ADR 0094：Nexus 节点信息导入与运行时接管分开

日期：2026-10-24。状态：采用。

用户要求将 Nexus 节点信息一起迁入 apsp，并保持原订阅链接。当前受管节点创建会生成新凭据，存在节点还会影响插件启用判定；直接调用普通创建接口会改变身份或发布状态。源节点还包含不同长度 Reality short ID、Hysteria2 跳端口、非一倍计量、自定义路由等尚未完成接管的配置。

在 sing-box 插件新增独立的已导入节点库存，展示于既有“代理服务 → 代理节点 → 节点库”，不新增 core 代理业务。按来源与原节点编号唯一关联，保留原实例和物理主机编号；主机映射必须与服务器资产中的来源标签一致。显示原配置的启用、隐藏、权限组、端口、倍率和明确白名单协议参数；状态固定为待 Agent 接管，不使用它伪造在线、部署或计量状态。

完整原始节点记录连同所属机器、主机映射、权限组、路由配置，逐节点存入现有 AES-256-GCM 凭据库。每份限 64 KiB，普通列表、预览和审计不包含私钥、证书密钥、外部出口认证或任意原始 JSON。复用宿主通用事务内凭据写入接口，数据与凭据同一事务提交或回滚，不新增加密依赖或信任根。

只有所有者会话可读取库存或预览，写入另需近期身份验证。预览和导入都把完整来源放入宿主已脱敏的 `payload`，避免 JSON 字符串中的私钥或未知字段落入通用审计；正文遵守 3 MiB 管理接口上限。先预览目标映射与摘要，再以相同摘要提交；来源导入串行化，同快照重试返回既有结果，内容变化和不完整库存拒绝覆盖。此阶段不提供静默刷新、删除或运行时发布按钮。未来正式接管应消费保存的身份并完成计量交接与运行时验收后，再引入新的状态转换。

库存导入不写普通 `nodes`、授权、`server_plugins`、部署或服务器脏标记，旧订阅和旧节点继续由原系统服务。资产、节点信息和运行时接管分别记录完成状态。
