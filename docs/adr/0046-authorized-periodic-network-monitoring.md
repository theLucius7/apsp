# ADR 0046：有授权范围的轻量三网周期监控

状态：已接受。

## 决策

Issue #63 的源码准备复用 `network_probes`、统一延迟任务、Agent 的四路调度、12 秒单次上限及持久化结果队列。运营商使用明确的电信、联通、移动标签，通用线路和未知标签仍支持；地区不从地址推断。无内置公网测点，不访问排名服务，不周期运行完整验机或修改宿主。

管理员登记目标为自有或已明确获准使用，保存来源记录与适用范围。声明不是平台自动核实第三方权利的证明。授权另绑定检测方式、精确目标、端口及网络版本；启用必须有有效授权。目标、网络版本、运营商和地区创建后冻结，改向或重新归类须新建，以免迟到结果进入其他目标的历史。名称、周期和停用可修改。

授权可撤销并可设绝对到期时间。新版 Agent 每秒检查运行许可，在 DNS 解析后按家族选择地址，每次 TCP 建连前重新检查；单次运行预算还受授权剩余时间限制。使用既有经认证面板校时偏移判断到期，不把主机错误时钟当作面板时间。配置撤销或到期取消未完成工作并丢弃迟到完成；已接受的历史、结果去重及目标删除后的确认语义保持。断连时无法立即知道面板的新撤销，沿用既有最多 24 小时配置缓存，并始终本地执行已知授权期限；这不是即时在线撤销保证。

## 协议及旧记录

`ProbeSpec.monitor` 可缺失或为空，故旧 JSON 原文保持且历史可读。缺授权的旧配置在新版执行器中无效；重新登记授权后才可启用。通过现有端点的 `authorization=1` 查询获得新字段。旧执行器拿到原字段且 `enabled=false`，避免它忽略缓存中的授权期限和家族。离线旧 Agent 已缓存的历史配置无法由源码或一次面板响应瞬间停掉；必须升级可执行器或由维护者受控停用旧服务。本变更不自动执行生产升级、停止旧服务或签发候选制品。

每次结果可携带实际 IPv4/IPv6；旧结果缺字段表示未知，不能从当前 DNS 或地区反推旧样本。延迟缺失及错误继续显示不可用，不产生零延迟。`execution_authorized` 仅是面板计算的展示字段，输入不被信任，Agent 执行只检查实际绑定授权。匿名看板保留地区、家族和此布尔状态，移除授权来源、适用范围、目标和端口。

## 与诊断任务的边界

新建 NodeQuality daily 或原生 TCP 诊断仅可复用已启用、授权有效、无授权到期时间且家族为自动选择的目标。有限到期授权不进入只冻结地址而不能继续传递期限的旧诊断快照；指定家族也不降级为忽略家族。既有 Started 任务仍按原冻结参数及精确版本恢复，不能用此新模型重写保存的 JSON。

此处到期与撤销守卫针对轻量周期拨测；未把共用诊断的历史运行改造成即时撤销服务。诊断运行仍受其原有预算、取消和生命周期保护，保存快照后发生的授权撤销与旧 Started 回收不据此宣称拥有精确授权截止保证。

## 验证边界

新增协议、真实回环及数据库测试源码覆盖授权缺失、伪造展示布尔、身份绑定、到期、撤销、家族过滤、历史与匿名字段。用户要求全部修复完成后统一执行验证，本 ADR 不声称已执行这些测试。小内存、磁盘不足、持续真实代理流量、正式候选升级后的重连与停用仍须独立实机验收；CI 暂停保持。
