# ADR 0058：阿里云 ECS 启停、自动策略与费用缓存

状态：已接受。

日期：2026-10-02。用户补充授权参考 CDT-Monitor 的手动/自动启停、流量阈值、两种停机模式、每日计划、抢占式保活、账单与余额缓存，覆盖 ADR 0057 暂不启停的边界。

## 决策

- 继续在阿里云面板插件实现，不向 Agent 传递云密钥。EIP 没有启停；ECS 按明确登记的地域和实例 ID 操作。只使用已有依赖。
- 手动启停先查询并预览，确认后进入持久任务。`StopInstance` 明确使用 `ForceStop=false` 和 `KeepCharging`/`StopCharging`；`StartInstance` 不初始化本地磁盘。异步回执不视为完成，读回终态与实际停机模式；不支持节省停机却降级普通停机时明确显示差异。
- 启停与原带宽变配共用账号锁，并检查同资源互斥。写请求前持久化意图，进程重启和未知回执只读回，不盲目重复写；已明确拒绝的保活请求按至少 15 分钟冷却创建新任务。取消仅适用于尚未发送的任务。
- 默认关闭自动启停。阈值支持 GB 额度、触发百分比、仅通知/停机并通知。依据当月完整 CDT 账单的账号合计 GB，沿用 ADR 0057：兼容 CDT 读数无可信账期，只展示，不用于授权启停。账单可能滞后，不承诺实时硬限额。阈值停机优先，达到后锁住自动开机；错误/过期数据不解除保护，新的完整低于阈值账单才解除。
- 手动停机留下持久暂停标记，手动开机或明确恢复自动策略才解除。每日计划使用明确显示的固定 UTC 偏移（默认北京时间），支持跨午夜；开/停机事件仅补执行最近 10 分钟，持久去重，不补跑过期日程。保活仅启动仍存在且处于停止状态的抢占式实例，遵循阈值、手动暂停和计划允许运行时段，不创建新实例或绕过竞价库存。
- 账单、余额缓存持久化，浏览器只读快照；CDT 控制证据每 5 分钟查询、15 分钟过期，实例月账单与账户余额默认缓存 6 小时，跨月失效，分别记录错误与重试时间。失败保留旧值及原时间，不填零，不混合币种，不因刷新页面请求云 API。
- 插件事件与投递队列持久化，复用面板 Telegram/Webhook 通道和模板，逐渠道投递。云资源事件不伪装成服务器事件；站内历史在插件页展示。

## 参考与验证边界

审阅 [CDT-Monitor](https://github.com/wang4386/CDT-Monitor/tree/148fd7823367a9618ec185e0f46559c491465470) 的客户端、策略、任务去重和 6 小时费用缓存，独立实现。核对阿里云 [StartInstance](https://www.alibabacloud.com/help/en/ecs/developer-reference/api-ecs-2014-05-26-startinstance)、[StopInstance](https://www.alibabacloud.com/help/en/ecs/developer-reference/api-ecs-2014-05-26-stopinstance)、[节省停机](https://www.alibabacloud.com/help/zh/ecs/user-guide/economical-mode) 及 BSS 官方 API 元数据。

节省停机仍可能收取磁盘/EIP 等费用，固定公网 IP 可能变化，启动依赖库存；抢占实例已释放不能保活。开发验证只使用回环替身及隔离 PostgreSQL，不调用真实启停、账单凭据或通知目的地；CI 继续暂停，真实云端验收另记。
