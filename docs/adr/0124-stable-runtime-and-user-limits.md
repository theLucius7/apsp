# ADR 0124：稳定内核与逐用户限制

2026-11-07，覆盖 ADR 0119 的旧内核选择。用户要求确认最新正式版的 Snell v6 支持并升级，同时增加逐用户限速和连接数限制；范围已确认：每台服务器分别合计。

## 决策

固定上游 `v1.14.4`、提交 `c005f35300ce76427dc285481ec5695f5b179cd2`，版本 `1.14.4-apsp.1`。上游已原生支持 Snell v6、`certificate_providers`、Hysteria2 `bbr_profile` 和 TLS `handshake_timeout`。只通过 `tools/singbox-runtime/user-limits.patch` 增加限制，不再叠加旧分支热更新、mieru 和旧依赖补丁。面板继续发布完整配置，通过原有 Agent 对账、配置检查和服务管理执行。

限制属于 sing-box 插件，保存在 `singbox_user_limits`；默认全为 0，不限。上传与下载分别以整数 Mbps 配置（1 Mbps = 125000 字节/秒），每项最多 1000000。连接数上限同为 1000000。编译器把同一代理用户在该主机的认证统计名显式合成一个组，不从不可信用户名推断业务 ID，不改流量账本、不改套餐周期、不写入客户端订阅。

内核在认证后的路由入口检查限制，TCP 逻辑连接与 UDP 会话共用原子计数，拒绝超额新连接；路由错误、关闭和回调只释放一次。每方向一个共享令牌桶，初始突发最多 32 KiB；覆盖多节点、并行连接和协议复用后的逻辑流。关闭与动态读写超时会中断排队。保留协议握手回报，但不暴露可被零拷贝绕过的底层读写器。进程重启重建令牌桶及会话；配置应用仍可能中断现有连接。

普通节点和已接管节点都经同一限制编译入口。限制只针对可识别的公共认证入口；链路内部凭据不重复计量，外部节点及尚未接管的旧服务不承诺执行。每台服务器单独计算，非全网总额。入口节点所在服务器执行该连接的用户额度，中转服务器不据内部链路凭据推断终端用户。

API 需要代理业务权限，写入需要近期管理员验证；版本号防止覆盖并发修改，事务内审计并触发相关服务器重新发布。界面区分已保存与服务器确认：需要当前配置匹配、目标版本已应用、健康且设备观测新鲜；离线和未应用不能显示为生效。

## 发布及数据库边界

未发布阶段仍仅初始化空库并核对基线。新表及运行时版本约束直接归入当前基线，现有生产基线通过显式一次性脚本接入，先备份并验证结构副本，部署前执行；程序不会自动迁移或删库。保留已部署历史版本事实，只放宽允许的新版本。

本地验证不等于签名发布或真实设备验收；工作流继续暂停。新运行时需签名、导入匹配制品后才可部署。当前构建仍为跨平台纯 Go，不包含需要 Cronet 原生库的 Naive 出站；Naive 服务端入站可用。不得把上游支持等同于本项目所有平台的制品支持。

## 验证

集中验证包括 Go 并发/限速/取消与期限测试、真实内核回环 TCP/UDP、原生配置检查、编译确定性、API 持久化/并发保护/待应用状态、前端构建与浏览器交互、当前基线和一次性接入。最终证据与未验证范围见本轮验收记录及 PROGRESS。
