# ADR 0054：链路写入时复核资源快照与原选择

状态：已实现，最终 Web 整合验证通过（TEST_ONLY）。日期：2026-10-02。

## 当前入口与问题

[#142](https://github.com/theLucius7/apsp/issues/142) 最初记录的是旧 `Chains.tsx` 两跳链路弹窗。当前主线已按 [ADR 0040](0040-mixed-chains-and-subscriptions.md) 将链路统一放在代理节点页，通过 `Nodes.tsx`、`ChainEditor.tsx` 和代理资源列表管理有序混合路径。原两跳链路仍作为历史资源展示，保留原 ID、入口、授权和版本证据。

当前入口已有 `useResource` 同步快照门禁：相关节点、代理资源或服务器 GET 开始刷新时立即失效，失败后保留旧展示数据，只有成功响应才能恢复写入。节点编辑、链路创建和删除处理器都在发送请求前调用该门禁，#139 的策略组、授权和套餐保护继续保持。

恢复成功还需要复核原选择。已有入口此前只检查节点协议、启用及引用数，没有同时确认它所属服务器仍启用且符合当前服务器筛选；选择失效后，下拉框也没有保存原值的明确占位。受管段的重复服务器检查使用选点时缓存的服务器 ID，无法准确反映刷新后的节点归属。这些是前端选择核验缺口，后端仍独立校验权限和当前拓扑。

## 写入规则

- 创建、已打开编辑器的提交以及删除确认均使用当前同步快照。任一相关 GET pending 或失败时，不发送 POST、PATCH 或 DELETE；旧列表、名称、地址、入口和有序代理段草稿保留，刷新及关闭仍可用。
- 新建入口服务器须在当前已启用服务器及入口筛选中。已有入口还须是当前 Reality 直连节点、处于启用状态、未授权且未被链路引用，其服务器和对应代理资源一致。筛选改变时同步更新引用，旧提交回调也复核新筛选。
- 入口和服务器选择失效时，下拉框保留原 ID 并显示原因，表单显示具体错误。恢复读取成功后，仅原实体重新满足条件或管理员明确调整选择才能提交，不自动改选另一台服务器或入口。
- 受管段逐项核对当前节点、对应直连资源及已启用服务器。重复服务器和路径校验使用当前节点服务器 ID，不保存可过期的服务器归属副本。入口服务器筛选只限定入口，其他已启用服务器仍可作为受管段。
- 已打开删除确认重新核对代理资源 kind 和 ID。资源消失后禁止删除旧实体，管理员仍可关闭确认。

资源列表另以同一只读事务计算 `entry_eligible`，仅给出是否满足入口独立性，不公开用户或授权身份。前端已有入口必须取得显式 true；未知或新增授权时保留原 ID、草稿且不发送创建请求。写入事务继续独立校验授权与拓扑。

混合路径顺序、订阅节点版本与更新方式、批量创建请求收据及后端校验沿用既有实现。该修复不改变拓扑模型、代理用户账本、凭据、运行时发布或真实机场来源。

## 验证与签收

新增 `web/tests/singbox-chain-snapshot-writes.mjs` 对实际构建的 Web 页面提供 TEST_ONLY 回环 API：分别保持节点、代理资源和服务器 GET pending 或令其失败，在同一个浏览器事件中刷新并强制调用原提交或删除回调，核对业务写请求为零；恢复后核对原草稿和明确请求内容。

桌面与手机用例同时覆盖代理节点和链路筛选入口、新建及已有入口、实体删除/停用/新增引用、服务器停用、受管段归属变化、即时改变服务器筛选、按服务器进入节点页，以及失败期间关闭编辑器。1440 和 390 像素两个宽度合计通过 68 个场景，确认 144 次被禁止的写入没有发出请求，并在原选择恢复后确认 58 次写入；夹具收到 948 个请求，外部请求、意外 API 和页面错误均为零。

本轮先执行 Bun 单元测试及生产构建：14 个文件中的 56 项测试、1278 次断言通过，TypeScript 与 Vite 构建通过。随后使用该构建产物执行 17 个相关浏览器脚本，全部通过并保存 55 张截图，其中包括本新增回归、原有 mixed-chain、资源快照、#139 写入保护、拨测修订冲突、诊断取消及授权入口回归。构建仅产生 Vite 对 528.02 kB 主包的体积提示，未导致失败。

执行记录 `web-final-20261002T014800Z` 保存每个命令的退出状态、日志、截图及前后文件清单。Web 源码清单覆盖 `web/src`、`web/tests` 及 Web 包配置、锁文件和构建配置；其聚合 SHA256 在测试、构建和浏览器执行前后均为 `ae03349b4a5c1323fad6191128aa90b299a34d0eb5a131654da3cf7a157322d7`。新 `web/dist` 文件清单的聚合 SHA256 为 `7663a5ec62a399c0019e1955998a79bc5e3701d4da459298cf211a15e992f6d1`，17 个浏览器脚本执行前后均保持一致。

以上结论限于本轮实际构建的 Web 和 TEST_ONLY 回环 API。它不签收 #143、#144 的原生 Agent、租约调度、系统服务清理或真实网络执行，也不证明真实设备、机场账户或生产混合路径可用；这些证据须由各自验收记录提供。CI 按当前安排继续暂停。
