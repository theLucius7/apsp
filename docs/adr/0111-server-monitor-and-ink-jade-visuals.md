# ADR 0111：服务器页即监控面板，界面改用「墨与玉」视觉

## 背景

2026-11-05 用户反馈“服务器面板没有展示出来”，并要求按交互哲学和功能整理界面、删去冗余、重新排版，“该画 UI 的地方画 UI，兼顾性能和美学”；随后补充“UI 太丑了，要像个艺术品”。

检查生产界面后的发现：

- 从服务器列表点开一台服务器，「概况」只有几张文字表格，没有实时图表和资源趋势。曲线、拨测和实时速率只在看板的单机视图 `/#/dashboard/{id}` 里，而这个视图只能从看板卡片进入。同一台服务器有两套“详情”，管理员常用的那套反而看不到监控面板。
- 一台服务器的页面有三套外壳（服务器详情、线路诊断工具页、运维页），返回方式和标题各不相同。
- 服务器列表在 1440 宽度下操作列被挤出屏幕；三个统计块与看板重复。
- 每张图表下方固定留出一块约 70px 的说明区，悬停前只写着“聚焦曲线或移入指针……”。
- 服务器的「插件」分页把同一台服务器的 sing-box 分成四块：只有一行的安装表、运行时说明框、版本对比、节点列表。
- 列表、看板、实时接口每次轮询都带上每台服务器约 26 KB 的进程明细（`process_resources`）：生产 17 台时服务器列表为 513 KiB，看板实时接口每 3 秒 458 KiB，前端每次还要整体解析和比较。去掉后分别为 104 KiB 和 49 KiB。界面从未使用这些字段，只有运维的「资源与能力」从数据库原行读取。

## 决定

### 一台服务器只有一个页面

- 新增共用的服务器监控面板（`web/src/display/ServerMonitor.tsx`）：处理器、内存、磁盘的环形仪表，实时网络与本期流量，资源趋势曲线，延迟与丢包，硬件与系统信息，网卡与磁盘读写，设备与采样状态。
- 服务器详情的「概况」就是这个面板，读取管理员自己的接口（`/api/servers/{id}`、`/history`、`/probes`）；公开看板的单机视图显示同一个面板，读取看板的过滤投影。隐藏服务器在详情页同样有曲线。
- 管理员在看板点卡片直接进入服务器详情；能读取服务器的管理员打开旧地址 `/#/dashboard/{id}` 时转到 `/#/servers/{id}`。访客和只有监控权限的管理员仍留在看板视图，地址不变。
- 服务器详情、线路诊断和运维合并为一个外壳：标题下写地区、分组、系统和架构；右侧是状态、刷新、编辑、接入 / 升级，以及「带此服务器打开」菜单（网络检测，实验功能开启时还有网络配置、自动化与维护）。分页收成一行，原来分页下方的“带此服务器打开”一行去掉。
- 「运维（实验）」分页跟随「显示实验与冻结功能」：默认不显示，正在打开时仍显示。地址 `/#/servers/{id}/fleet` 不变。
- 概况每 3 秒刷新，其他分页 15 秒，不再在设置类分页上做实时轮询。

### 删去重复，按任务排版

- 服务器列表：去掉三个统计块，总数、在线、离线、待接入写在列表标题旁；地区旗帜放在名称前；Agent 版本写在状态下，不再单独占一列；未填成本显示“—”；流量列带额度进度条；行内只留编辑和删除，名称本身就是进入详情的链接。
- 服务器「插件」分页：sing-box 合成一张卡片（状态、原因、设备支持与运行时版本、目标版本 → 已应用版本、此服务器的节点），之后是运行时运维和部署历史。插件中心的全部服务器视图不变。
- 概览：“各服务器的 sing-box 状态”17 行表格改为「代理网络」示意图——面板居中，厂商在内环，服务器在外环各自厂商的扇区；颜色表示 sing-box 状态，大小表示本期流量，红色虚线圈表示 Agent 离线，每台服务器都是进入其插件分页的链接。窄屏改为紧凑的状态网格。没有待处理事项时只显示一行。
- 面板设置：「看板访问」「功能显示」两个单开关表单合成「常规」一张卡片，开关即时保存，失败时恢复原状并说明原因。
- 费用与续费：每行的“编辑 / 续期 / 复制 / 删除”收成“续期、编辑”加更多菜单；下次续费旁标出“N 天后”，30 天内为警示色，已过期为红色。
- 图表：图例平时显示每条曲线的最新值；悬停或键盘移动时，读数浮在光标旁（窄屏横跨图表上沿），不再在每张图表下预留空白；纵轴宽度按最长刻度计算，不再截断“975.4 KiB/秒”这类标签。

### 「墨与玉」视觉

> 本节已由 [ADR 0114](0114-aurora-palette-backdrop-and-controls.md) 取代：配色改为「极光」，并新增背景图、按钮与交互规范和新标识。

- 色彩：暖白纸色底、深墨文字、唯一的玉色强调；深色主题为墨蓝底与发光的玉色。语义色（成功、警告、危险、信息）保持原含义。所有文字令牌仍满足 WCAG AA（`tests/contrast.test.ts`）。
- 层次：卡片 12px 圆角、细边加两层柔和阴影（`shadow-soft`、`shadow-lifted`，按主题定义）；页面背后是一层静态的玉色与墨蓝环境光。
- 字体与数字：系统字体栈优先 SF / Segoe UI Variable / 苹方 / HarmonyOS Sans / MiSans；标题略收字距，统计数字 26px。
- 侧栏：当前项是浮起的卡片色胶囊，图标为玉色；分组标题更轻。
- 标识：用自绘的标识替换通用图标——一条曲线连起入口、中转、落地三个节点。
- 登录页使用同一层环境光和浮起的卡片。

### 性能

- `latest_metrics` 在所有轮询的服务器读取中去掉 `process_resources` 与 `system_pressure`：`/api/servers`、`/api/servers/{id}`、`/api/dashboard/servers`、`/api/dashboard/servers/{id}`、`/api/dashboard/live`。运维的「资源与能力」照旧从数据库原行读取进程与压力数据。
- 新视觉只用 CSS 变量、静态渐变和阴影，不下载字体或图片；示意图是一次布局的静态 SVG，唯一的动画（面板脉动）是 HTML 层上的 `scale` 与 `opacity`，由合成器执行、不重绘图形，并遵守“减少动态效果”。

## 后果

- 管理员看一台服务器只需一个地方；看板保持公开展示用途。
- 依赖旧结构的浏览器测试随之更新：服务器详情、插件分页、面板设置开关、列表统计块、看板单机视图对管理员的跳转。
- 通过 API 令牌读取服务器列表的外部工具不再收到进程明细；需要时读取运维资料接口。
