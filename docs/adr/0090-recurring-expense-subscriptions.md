# ADR 0090：Wallos 费用订阅配置原生接入

用户要求将 Wallos 的订阅配置功能一起添加到 apsp。费用订阅表示需周期付款的服务，与代理成员购买的销售套餐分开。

新增独立 `plugins/expenses/panel` 插件，复用面板管理员、加密配置、每日汇率缓存及 Telegram/Webhook 投递。管理员可管理订阅名称、金额、币种、付款日期、日/周/月/年周期与倍数、分类、支付方式、付款人、备注、网址、自动续费、停用、取消日期、替代订阅和提前提醒。提供复制、续期、日历、iCalendar、预算与费用汇总、JSON 导入导出。

日期使用自然日，不以固定 30/365 天代替月/年。月末和闰日以原始付款锚点计算，跨短月后恢复锚定日。金额使用万分之一货币单位的整数，原币种金额是账面依据；换算展示必须注明汇率来源与日期，缺失汇率不当作零费用。

新增对锁文件已有 `time = 0.3.55` 的直接依赖，仅使用日期和时长类型，避免自行实现闰年与公历边界，也不增加另一套日期库。费用插件只依赖宿主和协议，不依赖代理业务插件。数据库继续追加同一迁移序列。

提醒默认关闭。启用后按配置时区生成到期事件，独立投递状态与有界重试，不修改其他通知规则。自动续费只推进计划日期，不声称代扣或已付款。手动续期记录用户操作。Wallos 导出仅读取订阅配置与分类、币种、支付方式、付款人，排除账号口令、API Key、SMTP 和通知凭据。
