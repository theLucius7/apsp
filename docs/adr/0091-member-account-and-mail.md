# ADR 0091：成员账号与邮件

补齐 Nexus 的邮箱密码登录、密码恢复、邮箱变更与通知设置，继续使用 sing-box 插件独立会话，不增加平台全局用户。成员也可使用既有 Passkey；两种认证均受同一停用、撤销与来源校验控制。

使用 `argon2 = 0.5`（锁文件已有）保存新密码，不导入旧密码或现有登录会话。邮件验证码绑定用途、邮箱、成员和随机挑战编号，十分钟失效、最多五次尝试、单次消费；邮箱变更需当前会话近期验证，并验证新旧邮箱。公开接口按连接地址、邮箱和全局窗口限流，不信任转发头。密码运算使用宿主已有并发许可和阻塞线程池。

新增 `lettre = 0.11.23`，只启用消息构建、SMTP、Tokio、rustls、ring、Mozilla 根证书。依赖理由是兼容现有 SMTP 发信配置并正确处理认证、TLS 和邮件编码；替代方案手写 SMTP 协议易产生降级及编码错误，仅提供 HTTP 邮件接口又会丢失现有配置能力。配置只接受 SMTPS 或强制 STARTTLS，证书必须通过验证，不提供明文与忽略证书开关。实现依据 [lettre 官方 API](https://docs.rs/lettre/0.11.23/lettre/transport/smtp/struct.AsyncSmtpTransport.html)。密码使用宿主凭据库引用，不进入普通配置、导出或审计正文。

默认关闭 SMTP 与主动邮件提醒。邀请通过 Passkey 开通时可登记联系邮箱；若启用邮件，领取前必须验证邮箱。邮箱密码登录只使用已验证邮箱。没有邮件配置时保留现有 Passkey 和管理员恢复流程，不把联系邮箱直接当作已验证身份。

到期、流量和邀请人提醒有站内记录及去重。主动邮件开启后才执行 SMTP；开发验证使用隔离数据与消息构建，不发送真实邮件。通知发送与业务付款分离，投递失败不能回滚已完成订单。

实际迁移补充：原成员 bcrypt 哈希按 ADR 0092 显式导入。原邮箱密码成功登录后升级 Argon2；修改既有密码可使用近期登录证明，不依赖未配置的 SMTP。首次设置无密码账户及修改邮箱仍须邮箱验证。
