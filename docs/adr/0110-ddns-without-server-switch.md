# ADR 0110：域名解析不再按服务器启用，页面按使用顺序重排

## 背景

[ADR 0048](0048-cloudflare-ddns.md) 让 DDNS 复用 `server_plugins` 的 `ddns` 标识，按服务器显式启用，默认关闭。这个开关不对应任何设备上的东西：DNS 更新在面板里执行，地址来自 Agent 已有的上报，设备上不安装、不运行任何程序。

结果是「域名解析」页面的大半是一张 17 行的「DDNS 插件启用状态」列表，每行都是「插件未启用」。添加规则之前必须先到这里给目标服务器点「启用」，否则保存被拒绝；规则自己又有启用/暂停。两层开关管的是同一件事。用户反馈：页面太乱，「插件未启用」是什么意思，为什么还要单独设置。

页面上其他问题：DNS 账号显示内部 UUID、「全服务器权限范围」「官方记录管理已接入」这类实现用语；没有规则时只有一句空提示；底部一段关于“已提交和已核对”的说明。添加规则的表单一次铺开二十个字段，包括凭据中心 UUID、线路标识、地址来源、TTL，而有了已保存的账号，实际只需要域名、服务器和 IP 类型。腾讯云、阿里云、华为云账号要先去凭据中心建凭据、再把 UUID 粘回来。

## 决策

- **去掉按服务器启用。** 所有接入 Agent 的服务器都可以绑定规则；规则自身的「自动同步」（`config.enabled`）是唯一开关。删除 `POST /api/plugins/ddns/servers/{id}/enable|disable`，`GET /api/plugins/ddns/servers` 不再返回 `enabled`，规则不再返回 `plugin_enabled`，同步、调度、迁移和创建不再检查 `server_plugins`。服务器删除或退役仍然阻止同步并保留解析。
- **迁移 0085 保持行为不变。** 升级时，绑定在开关关闭（或从未打开）的服务器上、但自身处于启用状态的规则，原本一直不会同步；把这些规则改为暂停并增加修订号，然后删除 `server_plugins` 中的 `ddns` 行。升级不会开始任何此前不会发生的 DNS 写入；要让它们运行，在列表里「恢复同步」即可。
- **一步添加任意提供方的账号。** 新增 `POST /api/plugins/ddns/accounts/access-key`，与已有的 Cloudflare 令牌接口对应：腾讯云、阿里云、华为云填写访问密钥对和可管理的域名（华为云为 Zone ID），面板加密保存为 DNS 凭据并登记账号，在同一事务内完成。需要再次验证，所有者权限与 Cloudflare 接口相同；密钥不回显，审计日志按 `access_key` 脱敏。
- **页面按使用顺序重排：**
  - 顶部只有「添加解析」；第一块是解析记录列表（域名、服务器、解析到的地址、状态），每行一个简短状态标签，异常时下面一行写原因；「立即同步」在宽屏上是图标按钮，编辑、暂停、核对与历史、删除收进「⋯」。
  - 第二块是 DNS 账号：名称、可管理的域名（显示域名而不是 Zone ID）、「管理记录」，检查连接和编辑收进「⋯」；「添加账号」一个入口，先选提供方。
  - 没有账号时，空状态直接引导「连接 DNS 账号」。
  - 添加解析时只填完整域名、服务器和 IP 类型：已连接账号里能管理该域名的最长区域自动选中，表单下方说明由哪个账号管理；找不到时提示并禁止保存。名称默认取域名。地址来源、TTL、检查间隔、Cloudflare 代理、自动同步和「只给这条解析单独填写凭据」放进「更多设置」。没有账号时仍可单独填写凭据，不强制先建账号。
  - 批量迁移的目标账号从列表选择，不再粘贴 UUID；DNS 记录对话框的区域显示域名。

## 取舍

- **保留开关，默认对所有服务器打开：** 改动最小，但“插件已启用”的列表仍然在，以后新服务器还要考虑默认值。开关不保护任何东西（规则不存在就没有写入），未采用。
- **迁移时把开关关闭的服务器上的规则直接放开：** 更省事，但会在升级时突然开始写 DNS。未采用。
- **账号与区域仍由用户手选：** 更直观地暴露账号，但大多数人只有一个账号，选两次下拉没有意义；同一域名出现在多个账号时按最长区域、再按账号创建顺序选第一个，提示里写明是哪个账号。

## 验证

- `apsp-plugin-ddns`：调度测试改为“没有服务器开关时规则照常同步，暂停的规则不被认领”，移除 `plugin_disabled` 相关断言。
- `apsp-panel --test ddns`：迁移 0085 测试（开关开启的规则保持运行；开关关闭和从未打开的启用规则改为暂停并加修订号；已暂停的规则不变；`ddns` 行被删除）；新接口测试（Cloudflare 与华为云域名名称被拒且不留下凭据；腾讯云账号一次保存，默认名称、区域规范化，响应、列表和密文中都没有明文密钥）。
- 浏览器测试 `ddns.mjs` 在 1440、390、320 宽度下覆盖：无开关、无账号引导、单独凭据创建与草稿保留、按域名自动匹配账号与最长区域、编辑不回传令牌、同步/暂停/恢复/删除、状态未知时禁止写入、双栈与名额、隐藏标签页不轮询、未登录不读取。
