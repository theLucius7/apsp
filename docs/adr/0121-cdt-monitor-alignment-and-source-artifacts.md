# ADR 0121：CDT 监控补齐与源码制品分离

日期：2026-11-07。用户要求参考本机 CDT-Monitor，补齐除每日汇总通知外的差异，包括高级 Cron 与守护组合；明确 CDT 查询已包含 IPv4/IPv6 总流量，不再增加分协议流量查询。用户同时要求纠正构建产物随源码提交。

## 决策

- 阿里云插件仍位于 `plugins/alicloud/panel`，页面仍为服务器分组的 `/#/alicloud`。用量、账单、余额分别展示采集时间与失效状态；IPv6 地址为只读展示，从实例详情解析，缺失时限时查询实例网卡，补查失败不影响启停与守护。
- 复用账号现有 CDT 总量查询，按中国内地、海外额度池分别保存小时及日末累计快照，保留 32 天。只保存成功观测，不把失败或缺失记为零，不新增 IPv6 流量查询。图表显示 24 小时／30 天累计值与相邻桶增量；跨月、回退、缺失桶增量留空，不干预守护账本。
- 高级计划支持五字段 Cron 的数字、通配符、列表、范围和步长，固定 UTC 偏移。后端校验并预览未来五次触发；不增加依赖。搜索按天跳过无关日期，有明确五年上限，避免任意分钟循环。日与周均受限时按通用 Cron 的“或”语义。
- CDT 守护可与每日／Cron 计划及抢占式保活组合：超限停机优先；计划停机不依赖新用量，CDT 限流退避与实例轮询分别计时；任何自动开机必须通过新鲜、低于阈值的守护观测、手动暂停和计划窗口检查。最近的计划事件为停机或无法确定窗口时禁止保活／守护自动开机；同一分钟开停冲突时停机优先。任务执行前重新检查条件，未知云回执仍只读回，不重复发送。原无计划守护配置保持兼容。
- 按用户后续要求使用本机较新工具链；Bun 统一为本地 1.4.4，依赖仍按现有锁文件安装，不作无关升级。
- 不增加日报。继续使用 Telegram/Webhook（含现有 Bark 预设）。
- `web/dist` 从 Git 索引移除并忽略，保留 `web/public` 原始资源；本地、CI 与 Docker 均先构建前端再构建面板。构建工具检查缺失前端并给出明确命令。已签名正式 Release 是独立发布渠道，不删除或重写历史；本轮不发布、不触发 CI。

## 验证

实现、界面、迁移、测试源码与文档一次完成后集中验证。云接口仅使用本地替身，浏览器仅使用本地模拟 API。记录源码身份、未运行范围和有界结果，清理本轮编译缓存，保留最新必要产物。
