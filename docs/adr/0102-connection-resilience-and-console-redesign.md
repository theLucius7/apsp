# ADR 0102：连接韧性与控制台重新设计

- 状态：已实现；本地构建、单元测试与浏览器回归验证，未在真实设备或生产面板上验收。侧栏分组与入口由 [ADR 0126](0126-workspaces-language-and-addresses.md) 取代；连接恢复部分继续有效。
- 日期：2026-11-01。

## 背景

用户反馈：页面有时闪烁一下、显示没连接上，界面展示和排版不好，代理用户管理不清楚，改权限、给登录地址、拿订阅链接都不方便。

用固定数据的回环面板实测旧版（400 毫秒往返、单次断线、挂起、网关 502），确认了这些现象的来源：

| 现象 | 实测 | 原因 |
| --- | --- | --- |
| 闪一下“无法连接面板” | 一次断线立刻插入红色提示，布局位移 0.04 | 每个 `useResource` 一失败就报错，页面上每个区块各报一遍 |
| 页面冻结，刷新不再更新 | 一次挂起的读取之后，25 秒内轮询次数为 0 | 读取没有超时；上一轮未结束时下一轮直接跳过，挂起一次就永远停止 |
| 明明已登录却跳到登录页 | 启动时网关返回 502 就显示登录表单，恢复后也不回来 | `/api/dashboard/access` 读取失败被当作“未登录” |
| 回到已访问的页面闪一下 | 用户页反复插入“相关信息正在刷新或刷新失败” | 每次进入都从空白重读，首屏读取期间写保护提示用红色告警显示 |
| 侧栏跳动 | 每次刷新页面，导航链接从 2 个变成 22 个 | 权限读到之前只显示两个入口 |
| 深色主题白屏闪 | 保存了深色的浏览器每次加载先亮一下 | 主题要等 JS 和接口才应用 |
| 整个应用白屏 | 任一页面渲染异常，外框和导航一起消失 | 没有错误边界 |
| 发版后页面打不开 | 打开中的标签页找不到旧的代码分块，只提示“加载失败” | 旧文件已被新版本替换，没有恢复路径 |

排版的问题集中在三处：一屏里同一个名字出现三次（面包屑、眉题、标题），第一行数据要到屏幕一半才出现，手机上几乎要翻一屏；服务器行高 120 像素，一屏只有 4 行；代理用户页高 4300 像素，登录入口排在最底下，订阅地址藏在对话框里，列表看不出每个人的状态。

## 决定

### 连接层

1. **失败分两类。** 没有得到面板应答（`ConnectionError`、网关 502/503/504 与 Cloudflare 52x 的错误页）是连接问题，由外框统一报告一次；面板自己返回的错误（含 JSON 错误信息的响应）属于这次请求，照旧立刻显示在页面上。
2. **确认后才告诉用户。** 请求失败只启动静默探测（1.5、3、6、12、15 秒退避，`/api/dashboard/access`）；探测也失败才显示连接提示。提示浮在页面上方，不改变布局，并说明显示的是哪个时间的数据。恢复后所有资源立即重读。短暂断线完全不可见。
3. **读取一定会结束。** GET 请求 20 秒超时，按连接失败处理。写请求不设超时，因为服务器可能仍在应用。
4. **启动失败不等于未登录。** 启动检查没有应答时停在启动页并自动重试，恢复后直接进入，绝不因此显示登录表单。探测发现会话在断线期间过期时才回到登录。
5. **回到标签页立即刷新。** 页面重新可见、浏览器恢复网络时立即重读，不等下一个轮询周期。

### 写保护语义调整（修改 ADR 0054、0075、0084 的部分决定）

**后台轮询不再使快照失效。** 手动刷新、写入后的刷新、路径切换和读取失败仍然立即失效，写入规则不变。

旧规则是“任一相关 GET 进行中就拒绝写入”，这带来两个代价：往返 400 毫秒时，页面有近十分之一的时间拒绝点击（提示“本次操作未执行，请稍候再试”）；每个读取完成时渲染一次，其他读取还没回来，按钮随之闪成禁用。

这条规则换来的保护也很小。轮询间隔内的数据本来就可能过期最多 5 秒，轮询进行中只是在这个窗口上多加一个往返。真正防止基于旧数据写入的是服务端的修订号校验（`revision`、`settings_revision`、`expected_revision`、`version`），这些都没有变。

轮询返回相同数据时不再触发渲染。

### 首屏与切换

6. **保留上次读取（`keep`）。** 主要列表页（概览、服务器、节点、用户、看板）再次进入时先显示上次的数据，新读取在后面进行。这份缓存只放内存，只用于显示，写保护把它视为未确认；登录和退出时清空。表单类读取不使用，避免用旧值初始化表单。
7. **主题先于首帧。** 主题和密度同时存在 `localStorage`，`index.html` 用内联脚本在首帧前应用。线上没有 CSP；如果以后加 CSP 拦截内联脚本，只是退回到旧行为。
8. **导航一次到位。** 侧栏权限信息（角色、能力，不含凭据）记在 `localStorage`，刷新时直接按它绘制，读到新值再修正，退出时清除。它只决定显示哪些链接，权限始终由面板校验。
9. **错误留在页面内。** `PageBoundary` 把渲染异常限制在当前页面，外框和导航可用，切换地址即恢复。
10. **发版后自动恢复。** 代码分块加载失败时，面板可达就自动刷新一次（60 秒内不重复），不可达才显示错误。空闲时预加载常用页面，切换不再等网络。

### 控制台外框

11. **一个页面只有一条顶栏。** 去掉独立顶栏和眉题，页面标题栏（`PageHeader`）吸顶，放标题、一句说明和操作，操作始终可见。搜索移到侧栏顶部，语言与主题移到账号菜单，连接状态常驻侧栏底部。
12. **侧栏固定宽度。** 去掉可拖动的分栏组件：它要在挂载后计算布局，并靠逐帧重试同步折叠状态。侧栏改为 CSS 固定宽度（224 / 56 像素），分组可折叠，「系统」和「实验功能」默认折叠，当前页所在的组始终展开，常用入口不用滚动。
13. **看板进入外框。** 登录后「服务器看板」是普通控制台页面，点开不再丢失侧栏，也不再有自己的主题开关；只有公开访问时才独立显示。
14. **紧凑的视觉基准。** 正文 13–14 像素、数字等宽、表格行约 44 像素、面板用细边框代替阴影。统计格只保留数字本身说不清的备注。服务器行操作收成图标按钮，无障碍名称不变。离线服务器的卡片不再模糊遮盖数据。动画只留给弹窗和菜单，页面切换不再位移。

### 功能合并（修改 ADR 0098 的导航结构）

用户要求“功能太多太杂，统一一下，去掉冗余和重复的”。本轮不删除任何数据、接口或地址，只合并入口和重复的操作：

- 侧栏从六组 22 个入口减到四组 12 个。讲同一件事的页面合成一个入口下的分页：服务器列表与看板、告警事件与设置、网络检测与延迟检测、概览与统计报表；面板设置、插件中心、备份、管理与安全、账号安全合成「设置」。
- 实验功能默认隐藏，与冻结功能共用「显示实验与冻结功能」一个开关。
- 同一设置只留一个位置：主题、密度和语言只在账号菜单；服务器列表自己的密度开关去掉，跟随全局。

### 代理用户页

15. **选一个人，三件事都在第一屏。** 订阅链接和登录地址两张卡片并排，下面就是权限与套餐；单独授权、流量明细、诊断收进分页，隐藏时不卸载，草稿不丢。
16. **列表就能看状态，一键复制订阅。** 新增只读接口 `GET /api/plugins/sing-box/users/overview`，一次返回所有人的套餐状态、用量、到期、策略组和登录开通情况，不含任何凭据。列表每行显示状态点和用量，并带复制订阅链接按钮。
17. **保留安全门禁，只减少步骤。** 订阅地址仍然需要 `proxy:write` 与五分钟内的再次验证，且读取留审计。之前要打开对话框、等预览、再点复制；现在点一次“复制订阅链接”，需要时弹出再次验证，通过后直接复制。开通链接仍然要输入管理员密码，一次性、十五分钟有效。

## 影响

- 依赖不变；`react-resizable-panels` 仍用于网络配置页。
- 旧地址全部可用。`/#/dashboard` 对已登录管理员改为在外框内显示，公开访问不变。
- 产品地图中“眉题使用分组名”的规则取消。

## 未选

- **轮询时继续拒绝写入，只隐藏提示：** 点击仍有约一成概率被拒绝，用户的抱怨只解决一半。
- **推迟点击，等读取完成后再执行：** 需要改写所有写入处理器，且旧验收明确要求不事后自动执行。
- **改用 WebSocket 或 SSE 推送：** 能减少轮询，但要改后端与部署路径（经过 Cloudflare），不是这次问题的根因。
- **把用户页做成列表与独立详情页两级：** 改权限和拿链接要多跳一次页面，违背这次要解决的问题。
