# ADR 0129：按 S-UI 补齐代理管理能力

2026-11-07，用户要求按比较清单的顺序全部实施，直接在 main 集中交付。覆盖旧 MVP 中相应协议、出口组与配置范围限制；不改变插件分层、单运行时、签名制品与生产部署边界。

## 范围与顺序

1. 将客户端模板版本声明统一到当前稳定版 1.14.4。
2. 普通代理用户暂停/恢复，按用户查询真实运行时连接并断开选中连接或当前全部连接。
3. sing-box/Clash 客户端模板、规则集、自动测速和地区分组，以及同一受管节点的多个公开连接地址。
4. DNS-01 证书、证书复用、服务端路由/DNS/出口配置、常见协议创建。
5. Naive 出站的 Cronet 制品支持，Cloudflared、Hysteria Realm 及授权范围内的端点配置。

## 边界

- 暂停保留凭据、授权和账本，统一资格计算同时停止订阅与受管配置中的授权；外部提供方的已下载凭据不在本项目执行范围。恢复不重置套餐时间或流量。
- 会话操作复用持久化运行时命令，绑定应用版本、有限认证主体、短期有效期和现有管理员权限；适配器仅访问带密钥的回环 API。内核补丁提供认证主体，禁止根据共享来源地址猜测归属。会话列表不收集目标地址，不改计量账本；离线、过期、截断均明确呈现。
- 客户端模板只可引用当前有权使用的出站；校验引用、循环、大小和协议。未知字段报错，不能静默丢失；模板与服务端配置分开。
- 服务端高级配置不得覆盖计量、受管认证、内部链路、用户限制及本地控制接口。配置仍经完整编译、原生检查、应用和健康回报。
- 证书 DNS 凭据只向使用该证书的受管运行时分发，不进入订阅、审计或普通读接口。真实 DNS 写入、公网证书签发、生产部署和正式发布不属于本地测试。
- 新能力按运行时实际构建特性和目标平台声明，不能把上游可选能力等同于所有制品可用。
- 数据库直接更新当前基线，同时准备显式生产接入脚本；不增加旧开发库自动升级。

## 验收

所有实现、界面、测试源码与文档完成后集中验证。覆盖资格停用/恢复、会话授权与版本变化、模板授权引用与循环、协议配置、证书秘密隔离、制品依赖、数据库接入、前端浏览器交互。实际公网及其他操作系统未运行的验证分别记录。

## 配置与制品选择

服务器配置使用受限原生对象，出站与端点标签以 `extra-` 开头；不能声明系统接口、任意文件路径、命令或覆盖受管控制接口。OpenVPN 端点使用当前内核的 `openvpn-client` 类型。Cloudflared 仅指向本机回环 VLESS 隧道入站，强制重写目标地址；已有内部链路规则优先。TLS 证书复用保存同机配置快照，相同 DNS-01 配置共享提供方与续期缓存，不引入跨服务器秘密广播。

新增 Go 构建依赖来自同一固定上游的既有可选模块，包括 Cronet、Cloudflared、用户空间 VPN 和 Tailscale。替代方案是额外独立进程，但会破坏单运行时生命周期和签名制品边界，因此启用上游可选模块；Rust/前端不新增依赖。模块版本和校验和受固定上游 go.sum 限定，平台实际链接其子集。Cronet 动态库另固定长度与 SHA-256，并进入最终制品签名清单。适配器按具体制品版本声明附件，保留已安装的签名旧制品用于回滚；这不新增旧开发数据库或协议回退。
