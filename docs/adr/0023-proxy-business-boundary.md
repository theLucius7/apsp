# ADR 0023：服务器核心与 sing-box 代理业务分层

状态：已接受；代码与数据的功能模块划分见 [ADR 0125](0125-feature-modules.md)。

## 背景

整改要求将服务器管理与代理业务分开，并保留现有用户、订阅、授权和历史流量。这项决策覆盖原 MVP 对服务器成本、账单流量配额及代理用户配额和周期的排除；其余已有协议、签名和特权边界继续适用。本 ADR 先固定边界，搬迁代码和接口由另一个独立 PR 实现。

## 决策

- core 管服务器身份、凭据、连接、心跳、系统遥测、网卡总流量、服务器续费到期和成本、按账单日计算的网卡配额、轻量周期拨测以及共用诊断任务。第三方探测目标须先取得对方同意，目标可配置。
- sing-box 插件管代理用户、节点授权、订阅、按用户统计的代理流量、配额、重置周期和到期。面板实现迁到 `plugins/singbox/`，管理接口使用 `/api/plugins/sing-box/...`；前端与后端同一版本切换。
- 系统管理员归“系统”，代理用户归 sing-box 插件，模型与界面名称明确区分。没有启用插件的服务器不显示代理业务入口。
- 用户 ID、订阅令牌、节点凭据、授权关系和历史流量保留。旧 `/sub/{token}` 路径长期作为兼容入口保留，已有订阅无需重新导入。
- 本次不重命名数据库表。先搬迁所有权和接口，稳定后另开独立数据库迁移 PR。
- 服务器网卡总流量与按用户代理流量保持各自语义。计量协议的 `epoch` 只标记计数器重置，用于对账；套餐周期使用独立周期字段，不能复用 `epoch`。
- 诊断任务服务负责创建、资源预算、同机互斥、持久化、取消、结果上传与历史；诊断插件只负责参数转换、执行和报告解析。先迁 NodeQuality 并保留历史，再接其他插件。

## CI 边界

`agent-core` 禁止引用代理业务的 `user`、`subscription`、`quota` 及其复数、蛇形和驼峰标识符，同时保留原来的运行时名称禁令。扫描覆盖 core 目录内所有文本文件、SQL、测试和注释。

Windows、macOS 和 FreeBSD 的原生账户 API，以及 SQLite 的 `PRAGMA user_version` 是系统接口，不表示代理用户。检查器仅在已有调用文件中允许具体 API 表达式；不豁免整个文件或整行。原生本地变量统一命名为 `account`，URL 凭据测试使用 `account` 占位符，避免业务名称歧义。新增例外需要说明系统 API 原因并增加验证，不能以例外掩盖业务引用。

## 验收和迁移约束

独立验收见 [核心与代理业务边界](../acceptance/proxy-business-boundary.md)。本 PR 验证 CI 能拒绝新增代理业务引用并保留现有原生系统 API；订阅兼容、服务器插件可见性及实际搬迁在后续 PR 验收，不能把文档和静态门禁通过作为搬迁完成证据。
