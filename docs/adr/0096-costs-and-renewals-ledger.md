# ADR 0096：费用与续费：服务器项目、付款记录与总览入口

- 状态：已实现；本地编译、静态检查与 PostgreSQL 集成测试见 [PROGRESS](../../PROGRESS.md) 本轮记录，未在生产面板上操作。
- 日期：2026-10-25。
- 落实：[ADR 0087](0087-narrow-positioning-proxy-network.md) 决定 4 的第一部分；在 [ADR 0090](0090-recurring-expense-subscriptions.md) 已部署的订阅费用插件上增量扩展。
- 关联：[功能地图](../product-map.md)、[Nexus 与 Wallos 迁移](../nexus-migration.md)、[待决问题](../open-questions.md)。

## 背景

ADR 0087 要求在“总览”新增「费用与续费」，以 Wallos 的方式统一记录服务器、域名和任意服务的周期费用。ADR 0090 的订阅费用插件已部署并导入了真实的 Wallos 数据，但只能记录手动项目，入口在「扩展」，服务器的价格与到期仍只在资产设置里。用户要求继续整合，并保证之前的配置继续可用、不直接废弃。

## 决定

1. **在已部署的插件上扩展，不另起账本。** 继续使用 `plugins/expenses/panel/`、现有 `expense_*` 表、接口路径和已发布的 `/#/plugins/expenses`；不改表名、不迁移或删除已有项目、提醒与导入记录。新增迁移 `0073_expense_payments.sql` 只增加一张表。
2. **服务器自动列入，只读。** 资产设置中设置了到期日期的服务器出现在「续费项目」下方、续费日历、30 天内续费和预计支出中，金额沿用资产价格与币种，按费用周期从到期日起推算；未填价格的服务器只列续费日。账本按调用者的服务器范围过滤，没有服务器读取权限时不显示；不写入服务器数据，修改仍在服务器详情。服务器的到期提醒继续由「告警设置」负责，账本不重复提醒。
3. **续期记录付款。** 确认续期时记录所覆盖周期的起点、付款日和金额；同一请求重试只记一次。删除项目时一并删除其付款记录。
4. **入口移到“总览”，显示为「费用与续费」。** 地址保持 `/#/plugins/expenses`，书签和搜索结果不变；界面中的“订阅”改称“续费项目”，以免与代理订阅混淆。已导出的 iCalendar 中，手动项目沿用原有 `UID`，重新导入时原地更新；服务器使用单独的 `expense-server-` 前缀。
5. **隔离恢复保持静默。** 恢复副本关闭费用提醒、成员邮件与支付渠道并取消待投递消息；Nexus 兼容桥保持原状，旧订阅地址和节点配置不受影响。

## 不做的事

- 机场订阅来源的到期引用：它属于 sing-box 插件，插件之间不能互相依赖，需要宿主提供续费项目来源接口后再接入。
- 运维资产档案中的续费与年度成本、退订提醒迁入账本，以及资产模型合并（路线图 3.1 后续与 3.2）。

## 验证

`crates/panel/tests/expense_subscriptions.rs` 新增服务器项目测试：价格换算、未填价格与无到期日的处理、一年预计与 30 天内续费、续期付款只记一次、手动项目的 iCalendar `UID` 保持原格式，以及账本不改服务器数据；插件单元测试覆盖服务器续费日推算与价格换算。`scripts/test-recovery.py` 覆盖隔离恢复语句。
