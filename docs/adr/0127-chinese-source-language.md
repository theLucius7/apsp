# ADR 0127：界面以中文为源语言，英文为翻译

状态：已接受（2026-11-08）。

2026-11-08 用户确认：保留 2026-10-06（`e1db1dc7`）起的英文界面翻译与语言切换，补记这项决策。此前协作规则写“界面只使用中文”，范围排除清单含“多语言界面”，与已经上线的界面矛盾。

## 决策

- 界面文字以简体中文为唯一源语言。新文字先写中文；英文是 `web/src/i18n.tsx` 静态词典中的翻译，词典里没有的文字在英文界面显示中文。
- 只提供简体中文与英文两种界面语言，不扩展为通用的多语言框架。按 [ADR 0125](0125-feature-modules.md) 拆分前端功能模块后，文案随各功能目录维护（[功能划分与逻辑结构 §5.5](../architecture.md#55-前端)）。
- 文档、PROGRESS 与 ADR 继续只用中文；代码标识符与注释继续用英文；对外文案（README、仓库简介、登录前的页面）的现行规则不变。

## 后果

- 协作规则中“界面只使用中文”改为本决策；排除清单中的“多语言界面”按本决策解释为：中英两种之外不再增加。
- 新增或修改界面文字时同时补英文翻译；英文界面出现未翻译的中文属于缺陷，不影响功能判断。
