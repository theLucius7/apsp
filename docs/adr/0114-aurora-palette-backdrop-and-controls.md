# ADR 0114：「极光」配色、背景图、按钮与交互、新标识

## 背景

[ADR 0111](0111-server-monitor-and-ink-jade-visuals.md) 合并后，用户要求“按钮大小、交互、网站 logo 都重新设计，更美观”，并补充“背景图片、配色也重新设计”。「墨与玉」的暖白纸色偏素，页面背后只有一层很淡的渐变光；按钮 32px、输入框 32px，在大屏上显得局促；交互只有颜色变化；网站没有 favicon，标识是三点一线的简单图形。

本 ADR 取代 ADR 0111 中「墨与玉」视觉一节；服务器页面结构、删去的冗余与性能部分不变。

## 决定

### 配色「极光」

- 浅色：带淡紫调的白底、靛蓝墨色文字、靛紫主色；深色：午夜靛蓝底、发光的淡紫主色。
- 语义色固定含义：成功翠绿、警告琥珀、危险玫红、信息天蓝（与主色的靛紫区分开）；图表另用紫、青、琥珀、玫瑰、青绿五色。
- 卡片与侧栏做成半透明（浅色 88% / 72%，深色 84% / 74%），透出背景，但不使用 `backdrop-filter` 模糊，滚动时只做一次合成混合。弹窗、下拉菜单与手机菜单保持不透明。
- 所有文字令牌在两套主题下仍满足 WCAG AA（`tests/contrast.test.ts`）。

### 背景图

- 自绘 SVG（`web/src/assets/backdrop-{light,dark}.svg`，各约 12 KB，gzip 后约 2 KB），由 `tools/web-backdrop.py` 生成：几片柔和的极光色场、三条用叠加描边做出柔和边缘的极光带，以及一层很淡的网络星图（节点与连线，对应代理网络）。只用渐变和细线，不用滤镜。
- 挂在 `body::before` 的固定层上，所有页面（控制台、登录、代理用户门户、成员页面、公开看板）共用；固定层由合成器处理，页面滚动时不重绘。文件带哈希，长期缓存。

### 按钮与控件

- 尺寸按 4px 递进：小 28、中小 32、默认 36、大 40；粗指针（触屏）下增大到 36 / 40 / 44 / 48。图标按钮同样递进。
- 主按钮：主色加自上而下的光泽、内高光和带主色的投影；悬停时投影抬高、亮度略升。描边按钮悬停时边框染上主色，幽灵按钮悬停时出现淡底。
- 按下时所有按钮轻微缩小（97%），给出触感反馈；减少动态效果时取消。
- 统一的聚焦光晕：主色 3px 柔光，按钮、输入框、下拉框、开关、勾选框、分段切换和侧栏项一致。
- 输入框与下拉框 36px，与默认按钮等高；悬停边框染色，聚焦时边框变为主色并出现光晕。
- 开关加大到 36×20，开启时轨道带主色光泽，滑块带轻微回弹；勾选框勾选时有一次小弹出动画。
- 分段切换：选中项为浮起的卡片，其余悬停变亮；页内分页：当前项主色下划线，其余悬停时出现浅色下划线。
- 刷新按钮每次点击图标转一圈；看板服务器卡片悬停时轻微上浮。

### 标识

- 新标识：一个“A”字形的线路，两脚是入口与落地、顶点是中转，横梁是一段弧线；放在紫到青的渐变圆角方块上，带顶部高光与细描边。控制台用可随主题使用的 `BrandMark` 组件，另有 `favicon.svg` 与 180px 的 `apple-touch-icon.png`。此前网站没有 favicon。

## 后果

- 新颜色、尺寸和交互全部集中在 `web/src/index.css` 的令牌与 `web/src/components/ui/*` 的基础组件中，页面不需要逐个修改。
- 按钮和输入框变高，表格行内的小按钮仍用 `xs` / `icon-xs`，行高变化有限。
- 背景图的颜色写在 SVG 资源中，不属于令牌；调整时改 `tools/web-backdrop.py` 后重新生成。

## 补充（2026-11-06）：图片与细节

用户要求“继续，你自己定，美化图片”“美化 UI”。在不改变上述规范的前提下补充：

- **背景图第二版**：极光带内加入柔和的竖向光幕（窄而高的椭圆，径向渐变四向淡出，不成条纹），底部加一道地平线微光；深色主题加一片稀疏星点。仍只用渐变与简单图形，无滤镜；浅色约 18 KB、深色约 27 KB（gzip 约 3–4 KB）。
- **登录页**：遵守 #219“登录前只显示 apsp”的决定，不加任何介绍文字；标识居中，外围两圈虚线轨道与节点缓慢旋转（一圈 60 秒，合成器旋转，“减少动态效果”时不转）。
- **页头图标**：一级页面标题旁显示与侧栏相同的图标块；带返回按钮的页面（服务器详情）不显示。
- **空状态插画**：共用空状态由灰色图标块改为小插画（主色光晕、虚线轨道与两个节点、浮起的图标卡片），全站空状态一起生效。
- **策略组内容**：一整段以「、」连接的节点名改为带旗帜的小标签，超过 8 个折叠为“+N”，可展开；读屏软件仍读到完整的一句。
- **趋势图曲线**：折线改为单调三次曲线（Fritsch–Carlson），经过每个采样点、两点之间不越出两者范围，不会画出未测到的峰谷（`tests/chart-smooth.test.ts`）。
