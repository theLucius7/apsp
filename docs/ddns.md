# DDNS 动态域名解析插件

当前支持 Cloudflare、腾讯云 DNSPod、阿里云云解析 DNS、华为云公网 DNS 的 A（IPv4）和 AAAA（IPv6）记录。DDNS 是按服务器启用的面板插件：Agent 沿用已有 IP 上报，面板插件保存凭据并调用所选提供方。无需给 Agent 安装额外程序。

## 使用

1. 在「插件中心 → 插件目录」找到「动态域名解析」，选择服务器，点击「启用 DDNS 插件」。也可从服务器详情的「插件」分页或侧栏「网络 → 动态域名解析」进入，后者统一管理多台服务器。
2. 选择提供方并准备域名范围的最小权限凭据。Cloudflare 使用 Zone ID 和 API Token，不使用 Global API Key；腾讯与阿里填写托管根域名及访问密钥对；华为使用公网 Zone ID 及 AK/SK。腾讯默认线路为 `0`，阿里为 `default`，其他线路需填写提供方线路标识。
3. 添加规则，填写名称、服务器、完整域名、区域信息和凭据，IP 类型可选「仅 IPv4」「仅 IPv6」「IPv4 和 IPv6」。支持 `node.example.com`、`*.example.com` 及中文域名；示例需替换为自己管理的域名。双栈只填一次表单和凭据，一次创建 A、AAAA 两条规则，保存后分别编辑、暂停或删除；占用两个规则名额，任一冲突或容量不足时整组不创建。
4. 默认每 300 秒检查，允许 60–86400 秒；Cloudflare TTL 为 1（自动）或 60–86400 秒；其他提供方为 60–86400 秒，同时受域名套餐下限约束，建议从 600 秒开始。Cloudflare 代理默认关闭，启用时 TTL 自动设为 1。代理只适用于 Cloudflare 支持的流量和端口，不能据此认定普通代理协议可用。
5. 勾选自动同步并保存。页面每 5 秒刷新运行状态，可查看本次候选地址、上次成功地址、最近成功核对、重试时间及错误说明。需要提前检查时点「立即同步」；手动操作至少间隔 60 秒，限流退避期间不可绕过。

首次遇到已有同名同类型记录，必须勾选「接管已有的同名同类型记录」才能管理。无记录时自动创建；有唯一记录时仅更新所选线路的地址、TTL 和适用的代理状态；不接管多值或负载均衡记录。多条同名同类型记录、CNAME/NS 冲突或区域不匹配会停止操作，请先在对应提供方整理。规则创建后提供方、区域、域名、类型与线路固定，换目标时另建规则。

## IP 来源与停止行为

- 服务器必须在线、未删除或退役，并且最近十分钟内收到 Agent 静态报告。升级数据库不会把旧缓存标为新报告。
- 只选对应家族的公网地址，跳过内网、回环、保留示例地址等。多个地址时优先沿用仍在报告中的上次成功地址，否则按数值顺序选择首个。不会把面板所在机器的公网 IP 用作节点 IP。
- NAT 后的服务器需要开启 Agent 的公网 IP 发现。报告时间是面板接收时间；Agent 已有的公网发现缓存最多保留三十分钟，不能将它当作每次同步刚完成的外部探测。如果有多个出口，请先检查候选地址是否符合该域名用途。
- 设备离线、报告过期、缺少某一家族地址时保留已有 DNS，不删除或写入空地址。一个家族失败不会修改另一家族的规则。
- 暂停规则、停用服务器的 DDNS 插件及删除规则都保留远端记录。停用插件保留本地规则和凭据，重新启用后继续对账；删除规则同时删除其保存的凭据。同步进行中，编辑、删除和停用返回忙碌，完成后再操作。

## 凭据、恢复与限制

Token 或访问密钥对按规则存于面板数据库，管理员读接口也不回显；编辑留空保留，填入新值替换；访问密钥对必须同时填写或同时留空。Agent、公开看板和错误正文不接收凭据。数据库备份包含凭据，应按秘密保护；当前不提供额外数据库字段加密。

最多 32 条规则，同时最多两个同步请求。数据库租约协调手动、周期任务和重启恢复；请求总预算 20 秒，租约 60 秒。失败按分钟指数退避，最大一小时，429 尊重有界 Retry-After。网络错误与超时会保留上次成功值，下次先重新读取远端；Cloudflare 与华为创建记录包含本规则标记；腾讯、阿里创建接口没有原子归属标记，若创建成功但回执丢失，下次会拒绝接管未知记录，需要在提供方核对后明确接管，不能仅凭 IP 相同认定归属。外部 API 与数据库不是同一个事务，不能保证超时意味着远端未修改。

「已更新解析」表示提供方接受且响应或读回与期望匹配；华为返回异步状态时只显示「已提交」，保留上次成功值，待后续 ACTIVE 核对才记成功，「解析一致」表示本次读取与期望一致，都不保证各地 DNS 缓存已经刷新。暂停或删除后如果要撤销域名，请在对应提供方手动处理。避免多个 DDNS 服务同时管理同一记录。

实现见 [ADR 0048](adr/0048-cloudflare-ddns.md)、[ADR 0056](adr/0056-multicloud-ddns.md) 和 [ADR 0060](adr/0060-ddns-dual-stack-creation.md)。本地测试使用私有回环 API；真实凭据、四家 DNS 写入、传播及长期动态地址变化需要在自己的测试域名另行验证。CI 暂停安排保持。
