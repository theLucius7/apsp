# DDNS 动态域名解析插件

当前支持 Cloudflare、腾讯云 DNSPod、阿里云云解析 DNS、华为云公网 DNS 的 A（IPv4）和 AAAA（IPv6）记录。DDNS 是面板插件：Agent 沿用已有 IP 上报，面板保存凭据并调用所选提供方。设备上不安装任何程序，所有接入 Agent 的服务器都可以直接使用，不需要按服务器启用（[ADR 0110](adr/0110-ddns-without-server-switch.md)）。

## 使用

1. 打开侧栏「服务器 → 地址与域名」，或服务器详情里的「地址与域名」（只显示这台服务器的解析）。
2. 第一次使用先在「DNS 账号」点「添加账号」。Cloudflare 只需一个权限为 DNS 编辑的 API 令牌，保存时自动找出它能管理的域名，不使用 Global API Key；腾讯云、阿里云填写访问密钥对和托管的根域名，华为云填写 AK/SK 和公网 Zone ID。建议使用只有 DNS 权限的子账号密钥。账号加密保存，之后不再显示；用户专属地址也从这里选择账号。
3. 点「添加解析」，填写完整域名、服务器和 IP 类型（「仅 IPv4」「仅 IPv6」「IPv4 和 IPv6」）。面板按域名在已连接的账号里找到管理它的最长区域，表单下方显示由哪个账号管理；找不到时不能保存。支持 `node.example.com`、`*.example.com` 及中文域名；示例需替换为自己管理的域名。双栈一次创建 A、AAAA 两条规则，保存后分别编辑、暂停或删除；占用两个规则名额，任一冲突或容量不足时整组不创建。
4. 域名已经有解析记录时，勾选「接管已有的同名记录」，否则同步会停下并提示，不做修改。
5. 其余设置在「更多设置」里，一般不用改：名称（默认取域名）、IP 从哪里来、TTL、检查间隔、Cloudflare 代理、自动同步，以及「只给这条解析单独填写凭据」（不使用已保存的账号时，按提供方填写 Zone ID 或托管根域名、线路和令牌/密钥对；腾讯默认线路为 `0`，阿里为 `default`）。默认每 300 秒检查，允许 60–86400 秒；Cloudflare TTL 为 1（自动）或 60–86400 秒，其他提供方为 60–86400 秒且受域名套餐下限约束，默认 600 秒。Cloudflare 代理默认关闭，启用时 TTL 自动设为 1；代理只适用于 Cloudflare 支持的流量和端口，不能据此认定普通代理协议可用。
6. 列表每 5 秒刷新：每行显示域名、服务器、当前解析到的地址和状态，地址将要改变时同时显示 DNS 现有的值；异常时状态下一行说明原因。宽屏上点行尾的同步图标可提前检查，其他操作（立即同步、编辑、暂停/恢复同步、核对与历史、删除）在「⋯」菜单里。手动同步至少间隔 60 秒，限流退避期间不可绕过。

首次遇到已有同名同类型记录，必须勾选「接管已有的同名同类型记录」才能管理。无记录时自动创建；有唯一记录时仅更新所选线路的地址、TTL 和适用的代理状态；不接管多值或负载均衡记录。多条同名同类型记录、CNAME/NS 冲突或区域不匹配会停止操作，请先在对应提供方整理。规则创建后提供方、区域、域名、类型与线路固定，换目标时另建规则。

## IP 来源与停止行为

- 服务器必须在线、未删除或退役，并且最近十分钟内收到 Agent 静态报告。升级数据库不会把旧缓存标为新报告。
- 只选对应家族的公网地址，跳过内网、回环、保留示例地址等。多个地址时优先沿用仍在报告中的上次成功地址，否则按数值顺序选择首个。不会把面板所在机器的公网 IP 用作节点 IP。
- NAT 后的服务器需要开启 Agent 的公网 IP 发现。报告时间是面板接收时间；Agent 已有的公网发现缓存最多保留三十分钟，不能将它当作每次同步刚完成的外部探测。如果有多个出口，请先检查候选地址是否符合该域名用途。
- 设备离线、报告过期、缺少某一家族地址时保留已有 DNS，不删除或写入空地址。一个家族失败不会修改另一家族的规则。
- 暂停和删除规则都保留远端记录。暂停保留本地规则和凭据，恢复同步后继续对账；删除规则同时删除其单独保存的凭据。同步进行中，编辑和删除返回忙碌，完成后再操作。
- 2026-11-05 之前 DDNS 需要按服务器启用。升级时，绑定在未启用服务器上的启用规则会改为暂停（它们此前也不会同步），需要时在列表中恢复同步。

## 凭据、恢复与限制

DNS 账号的令牌或密钥对加密存于凭据中心；单独填写的 Token 或访问密钥对按规则存于面板数据库。管理员读接口都不回显；编辑留空保留，填入新值替换；访问密钥对必须同时填写或同时留空。Agent、公开看板和错误正文不接收凭据。数据库备份包含凭据，应按秘密保护；当前不提供额外数据库字段加密。

最多 32 条规则，同时最多两个同步请求。数据库租约协调手动、周期任务和重启恢复；请求总预算 20 秒，租约 60 秒。失败按分钟指数退避，最大一小时，429 尊重有界 Retry-After。网络错误与超时会保留上次成功值，下次先重新读取远端；Cloudflare 与华为创建记录包含本规则标记；腾讯、阿里创建接口没有原子归属标记，若创建成功但回执丢失，下次会拒绝接管未知记录，需要在提供方核对后明确接管，不能仅凭 IP 相同认定归属。外部 API 与数据库不是同一个事务，不能保证超时意味着远端未修改。

「已更新解析」表示提供方接受且响应或读回与期望匹配；华为返回异步状态时只显示「已提交」，保留上次成功值，待后续 ACTIVE 核对才记成功，「解析一致」表示本次读取与期望一致，都不保证各地 DNS 缓存已经刷新。暂停或删除后如果要撤销域名，请在对应提供方手动处理。避免多个 DDNS 服务同时管理同一记录。
