本次用户已授权实际迁移、旧网页跳转及保留原订阅。实现分支已整合 main `21b1a067`（包含 PR #173/#174），加入迁移 0066–0069、成员运营与费用插件、统一界面、白名单导出及本机兼容同步器。设计见 ADR 0089–0092；操作流程见 [迁移说明](../nexus-migration.md)。

## 迁移盘点与隔离验证

源部署只读盘点：43 位成员、2 个套餐、56 个订单、16 个邀请、53 条钱包流水、88 篇指南、2 个充值、12 个支付意图、2 个回执、0 个支付异常；Wallos 11 个订阅。原业务当前已结算，邀请均已使用。最终切换前需要重新盘点，以上不是最终迁移结果。

测试源码覆盖并发钱包购买/幂等、邀请及预付退款、独立会话与来源校验、导入编号/期初余额/历史去重、原 bcrypt 登录和升级、套餐周期与原用量、订阅链接保留、EPay 重复/迟到回调、费用月末日历/精度/版本/导入重放、导出隐私和只读、兼容器身份冲突整批回滚，以及 1440/390/320 界面流程。

已完成本轮前端依赖冻结安装、196 项 Bun 测试（2494 条断言）、TypeScript/Vite 构建及提交用 dist；1440、390、320 像素的成员、运营套餐、指南过滤和订阅费用浏览器流程通过。Python 4 项测试覆盖私密只读导出、金额、原价格单位、密码哈希选择导出、已删除成员历史和兼容批次回滚；兼容测试还覆盖旧库财务/归档触发器、新身份余额为零、续期、停用/恢复和重复执行；兼容后端刷新脚本通过 PHP 语法检查。架构边界与差异空白检查通过。

PostgreSQL 16 隔离演练使用当前生产只读快照：43 位成员、余额合计 1,180,881 分、2 个基础套餐/4 个销售周期、4772 条历史、88 篇指南；Wallos 11 个订阅、49 个分类/付款方式/付款人。成员编号、令牌、UUID、密码哈希、期限、套餐配额、用量和提醒偏好逐字段一致，历史记录逐条 JSON 比对一致。8 条已删除成员的历史重置记录保留原编号，不制造当前账号。对旧 SQLite 的私密副本执行兼容交换：43 位成员、0 新建、0 改动，身份与流量计数完全一致。随后在该副本测试续期、创建、停用和恢复，原钱包及流量计数不变，旧触发器保持启用。永久套餐后来改为有限期限的原生分配也有数据库/API 回归覆盖。

EPay 专用测试使用隔离密钥环运行：重复回调、迟到回调和异常处理不会重复充值，1 项通过，未访问真实网关。首轮全工作区测试在成员场景发现两处测试夹具错误：来源校验预期与宿主的 HTTP 400 约定不符，以及示例 bcrypt 哈希与测试密码不匹配。改用实际 PHP 生成并验证的哈希，保留错误正文及余额不变断言；成员回归已通过，继续完成 51 组面板测试（235 项通过、7 项按条件忽略）、其余 7 个包（473 项通过）以及全工作区文档测试，三个补验命令均返回 0。结合首轮已通过的 577 项，去除重复前端用例并计入专用 EPay 补验，共 1284 项通过；其余 25 项依赖真实运行时、设备或虚拟认证器，仍未执行。最终 `cargo fmt --all --check` 与 `cargo clippy --workspace --all-targets -- -D warnings` 均通过。Rust 使用 1.98.1、隔离 PostgreSQL 16 及夹具发布公钥；这些公钥不会进入生产镜像。正式 Docker 镜像使用部署环境原有信任根构建，生产切换在源码合并后执行，最终结果留在私密部署报告。GitHub Actions 继续暂停，不触发或重跑。真实付款、邮件、Telegram/Webhook 不属于隔离测试；不会将未运行的外部能力记为通过。原节点的 Agent 接管仍为后续工作，当前订阅及协议继续由兼容后端服务。
