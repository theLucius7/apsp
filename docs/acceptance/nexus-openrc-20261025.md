# Nexus OpenRC 接管准备验收（2026-10-25）

基线为 main `31c15000e138c8e9278a126475d45493c6c96656`，实现见 ADR 0100。此记录区分本地源码验证、正式签名发布和生产接管。

## 实现与隔离验收

- Agent 版本准备为 0.3.3；OpenRC 使用独立的非特权采集进程和私有 UNIX socket。每流 8 MiB、一小时、16 KiB 单行及最多两个读取者；逐连接正文不写文件，core dump 软硬上限为零。会话流按时间顺序重放，管理员有限扫描从最新记录开始。
- 实际 musl Agent 在一次性 Alpine 3.24.2 / OpenRC 容器内运行采集命令。验证采集 UID、0700 目录、0600 socket、core dump 上限、仅 socket 而无日志文件；重装和重启 Agent 后运行时及采集进程 PID 保持，仍可重放此前日志。
- 同一场景覆盖 HUP、运行时和 Agent 异常恢复、默认 runlevel、旧版 Agent 服务模板选择、注册失败与激活失败回滚、原模板逐字节恢复、只读状态快照及 systemd 安装命令契约。真实 Agent 在 OpenRC 上仍拒绝缺少 systemd 保护的诊断任务。
- 容器中的运行时、签名验证及注册流程使用明确标注的公开测试夹具；实际 Rust 二进制只验证采集和诊断边界。没有将该场景等同于正式签名制品或真实公网客户端验收。

## 本地验证结果

- 新增 9 项内存日志单元与 IPC 测试覆盖重连重放、容量/过期、超长行、错误请求、读取者上限、文件与已运行 socket 拒绝、权限拒绝及新旧顺序。
- Agent 与 core 回归首次运行缺少 CI 的公开测试信任根，修正构建环境后 Agent 的 2 项及 core 的 294 项通过，core 另 9 项条件忽略、1 项失败。唯一失败是实例互斥夹具依赖 umask：本机 0002 使临时目录被正确拒绝。现已显式设置 0700，在原 0002 环境下该项补验通过（0.02 秒）；修复只改测试夹具，未放宽产品权限检查。
- 全工作区 `cargo clippy --locked --workspace --all-targets -- -D warnings`、格式、核心边界和差异空白检查通过；本机 OpenSSL 开发文件显式指向系统头文件和库，没有修改生产软件包。
- Python：bootstrap 25 通过、3 条件跳过；签名发布 37 通过、7 条件跳过；独立 bootstrap 制品合同 8 通过；托管路径合同 31 通过；签名夹具 1 通过；OpenRC 夹具 3 通过、1 需 root 的本机跳过，真实容器中 4 项全部通过。
- 最终摘要记录源码文件摘要与实际测试二进制摘要。完成后清理本轮编译目录、容器及镜像；生产身份、正式签名制品、远端回滚归档和私有迁移快照保留。

## 生产状态与未验证范围

生产仍为已签名 Agent 0.3.2 的 9 台主机、14 个节点。此前 12 个可用节点的旧客户端检查通过；另外 2 个节点外部出口在迁移前已故障。旧订阅地址继续返回内容，旧站根路径跳转至新面板。每台已接管主机均有会话归属、旧设备状态交换和新增正流量投递验收。

剩余 OpenRC 主机 SSH 正常，整盘 1 GiB，且无 Python。经检查发现两份旧路由备份；已在主机外保存归档、逐文件核对全部 10 个摘要，并确认没有进程或服务引用后移除主机上的重复备份。根分区可用空间由约 47 MiB 增至 175 MiB，当前旧程序、配置摘要及服务状态保持。用户不能在服务商扩容，后续按签名制品的实际大小分别预算根分区和临时内存盘，保留旧服务回退材料；安装依赖约增加 38 MiB，不能直接沿用 systemd 主机的安装与回退脚本。

Hysteria2 原始客户端在迁移前因证书过期失败。用户决定暂时停用这个节点，保留配置和记录，继续迁移同机的 VLESS；因此补齐静态证书的只读导出和显式禁用节点的快照转换。停用节点仍列入整台主机的快照，候选不得包含其监听，不能通过遗漏节点或放宽 TLS 校验绕过接管要求。原跳跃端口范围保留在加密来源档案及转换摘要中，停用快照不将其缩成单个公开端口；重新启用仍须另行审查证书和防火墙转发。3 台有节点主机仍受 SSH 连接/信任条件阻止，另 1 台没有节点的主机 SSH 超时。

该补充步骤的 7 项 Python 快照测试覆盖显式停用、完整清单、范围保留、缺失材料、未知节点和候选意外监听。旧节点自身 Go builder 的 2 项测试通过，实际只读导出保留原静态证书，VLESS 有效配置与此前导出完全一致。证书读取有大小和文件类型限制，校验密钥配对；没有续期、生成新证书或改变 TLS 校验。
