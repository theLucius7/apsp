## 真实部署盘点

源库存包含 15 台主机、21 个机器实例、31 个节点（27 VLESS、2 Hysteria、2 Shadowsocks）。读取既有 SSH 配置并使用已保存指纹验证，10 台主机可登录；其中一台为 Alpine/OpenRC，其余已观察主机使用 systemd。9 台主机的公开 apsp 健康路径返回 200；另一台缺少 curl，未将工具缺失记为网络故障。

其余 5 台：1 台没有 SSH 连接记录、1 台没有已确认主机指纹、2 台 SSH 超时、1 台跳板转发超时。原资产备注有主动关机记录，但也存在已标关机却当前可登录的记录，必须分别保留配置与观测事实。

GitHub 当前公开 `agent-v0.3.0` 的已签 metadata 与现行仓库/二进制名称校验不一致，其适配器只接受 VLESS。对身份差异的读取不是完整签名验收；本轮没有篡改已签资产、生成替代信任根或使用测试密钥。

已先备份目标 PostgreSQL，再通过正常管理员 API 导入 15 台主机资产。读取目标 API 核对 15 个唯一服务器 ID，所有已映射资产字段一致，没有伪造设备公钥、在线状态或遥测。Agent 安装数、节点运行时迁移数均为 0；原节点、计量兼容服务与原订阅路由保持。私有快照、SSH 现场材料和收据在操作者工作目录，真实地址与凭据不提交。

兼容差异统计：26 个节点的 Reality short ID 不符合当前固定八位校验；17 个节点的倍率不为 1；5 个包含 VLESS 多路复用；5 个包含自定义出口或规则；2 个使用跳端口和外部证书。另有 3 个 VLESS 配置标记启用加密但密钥值为空，必须核对实际生效配置，不能仅据开关推断协议。

CI 按仓库要求暂停。本轮未运行完整验机、性能压测、真实付费操作或通知发送；不能将只读 SSH 盘点标记为完整硬件或代理链路验收。

导入后再次导出源基础设施快照，配置摘要相同。原订阅两种权限组 × 默认/sing-box/Clash Meta 共 6 次读取均为 HTTP 200、非空且无跳转；这验证旧订阅端点仍可读，不替代真实客户端代理流量测试。成员 43、钱包余额合计 1,180,881 分、历史记录 4,776、费用订阅 11 均保持，兼容服务运行且心跳正常。
