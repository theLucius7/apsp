# 2026-10-24 界面第四轮：链路表手机布局与行操作分主次

用户要求继续优化界面。本轮处理上一轮留下的两项：有序链路表在手机上要横向滚动，链路操作列最多有 7 个文字按钮挤在一起。截图复查时又发现，桌面宽度下有序路径文字会溢出到相邻的“资源与授权”“累计流量”列。路线图 0.2“界面体现分级”仍等待决定 D6，本轮不做。没有新增依赖：下拉菜单来自已有的 `radix-ui` 1.7.0。

工作在分支 `claude/dreamy-heisenberg-w2g0rn` 上进行。开始时 PR #174 尚未合并，本轮修改基于其提交 `ff73086`；验证期间维护者已把 PR #174 与 #173 一起整合进主线（`21b1a06`），因此本轮提交改为在最新主线上重新整理，另开新 PR。全部修改完成并冻结后集中验证。远端 CI 继续暂停，未触发、重跑或恢复。没有发布、部署，也没有访问真实设备或生产面板。

## 截图发现的问题

- **桌面溢出：** 表格单元格继承了 shadcn 表格的 `whitespace-nowrap`，有序路径即使限制了最大宽度也不换行，文字压到右侧两列上。
- **手机：** 表格固定最小宽度 1080 像素，手机上只能横向滚动查看。
- **操作列：** 详情、路径与引用、整理、部署、编辑公开信息、应用节点新版本、创建替代链路、删除，最多 8 个文字按钮挤在一格内，换行后参差不齐。
- **其他：** 入口详情中的服务器链接带按钮内边距，与上下文字错位；面板说明区上方有一段空白。
- **验证阶段截图另外发现（第一轮重构遗留）：**
  - 顶栏位于固定高度的滚动列中，会被压回 56 像素最小高度。768–1023 像素宽时语言选择、1024–1279 像素宽时“管理员会话已登录”换到第二行，溢出顶栏，压在页面内容上。所有管理页面都受影响，现有夹具的宽度（1440/1280/390/320）都碰不到。
  - 节点库在 768–1199 像素宽（侧栏展开）时仍显示表格：公开地址被挤成每行几个字符，操作列被截断。节点名后的“直连节点 · 协议”和状态说明紧贴前一段文字，没有换行，原因是旧样式中单元格内 `small` 换行显示的规则已删除。

## 修改内容

- **有序链路表：**
  - 去掉固定最小宽度，单元格允许换行并顶部对齐。
  - 按所在面板宽度（CSS 容器查询，面板窄于 56rem 时）切换为卡片：名称在上，其后依次是状态与授权、累计流量、入口、出口，最后是操作；每格显示列名，面板宽于 28rem 时两两并排。
  - 仍是同一张表，显式标注表格、行、单元格和列头角色，表头只在视觉上隐藏，屏幕阅读器和现有测试定位不变。
- **行操作分主次：**
  - 新增 Nova 风格的 `components/ui/dropdown-menu.tsx`，以及共用的 `components/action-menu.tsx`（“更多操作”）。
  - 链路行直接显示“详情”“编辑公开信息”（直连为“编辑”）“删除”。“路径与引用”“整理”“部署”“应用节点新版本”“创建替代链路”收进菜单，按用途分组。
  - 有序链路的“详情”本来就打开路径与引用弹窗，菜单中不再重复。
  - 同页的节点库采用同一规则：直接显示“详情”“编辑”“删除”，“部署”“整理”“复制”进菜单；上移/下移改为 Lucide 箭头图标按钮，无障碍名称不变。
  - 菜单非模态，只有进入动画，关闭后立即移除。选择菜单项时先把焦点交还“更多操作”按钮。
- **弹窗焦点：** `Modal`、`Confirm` 记住打开时获得焦点的元素，关闭后还给它。此前所有弹窗关闭后焦点都落到页面开头。
- **细节：** 入口详情中的服务器名改为普通链接样式；面板说明区改为带分隔线的紧凑说明行；资源名称列设最小宽度，资源标识不再从中间断开。
- **顶栏：** 不再被压缩，内容换行时随之增高。平板宽度下面包屑只显示当前页面（侧栏已显示分组），搜索按钮从零起按剩余空间伸展、最宽 18/20rem，“管理员会话已登录”只在 1280 像素及以上显示，768–1279 像素宽时顶栏保持一行。
- **节点库：** 与有序链路表一致，按面板宽度（窄于 56rem）切换为卡片，不再只看视口宽度；单元格允许换行，名称和地址设最小宽度；类型与协议、状态说明、备注分行显示。
- **测试：**
  - `ordered-chains.mjs` 在 1440/390/320 宽度检查以下各项：
    - 布局：行在窄面板中为卡片、宽面板中为表格行；表格容器不横向溢出，单元格内容不溢出；列头仍可被辅助技术读取。
    - 菜单：直接显示的操作齐全；菜单可用键盘打开，打开后第一项获得焦点，方向键可移动；Esc 关闭后焦点回到按钮；菜单不超出视口，有序链路的菜单不含重复项。
    - 焦点：关闭弹窗后焦点回到打开它的“详情”按钮；从菜单打开的弹窗关闭后，焦点回到“更多操作”按钮。
  - 原先直接点击的“创建替代链路”“应用节点新版本”“路径与引用”“整理”“复制”“部署”改为先打开所在行的“更多操作”菜单。`singbox-business.mjs` 改为点击有序链路的“详情”，打开的是同一弹窗。断言意图不变。
  - `command-palette.mjs` 新增 768/900/1024/1100 像素宽的顶栏检查：控件都在顶栏内，顶栏保持一行。
  - `node-catalog.mjs` 增加 1100 像素宽，按面板宽度预期卡片或表格并断言实际显示的是哪一种。
