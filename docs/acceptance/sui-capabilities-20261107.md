# S-UI 能力补齐验收（2026-11-07）

源代码基于 `287de2b2`，本文件所在交付提交确定最终源码。对照 ADR 0125；使用方法见 [代理管理说明](../singbox-management.md)。

## 当前实现

- 普通代理用户暂停与恢复统一经过资格计算；保留用户身份、令牌、授权、套餐及账本。
- 用户连接按认证主体查询，逐连接或每批最多 256 条断开；绑定已应用配置版本，支持离线、过期和截断状态。速率为两次查询间的计数差值，不等同于套餐流量。
- sing-box 1.14.4 与 Clash 模板可配置选择、测速、故障切换、名称筛选地区组、DNS、分流与规则集；引用和环路校验，空组拒绝生成。多个公开地址不增加服务端监听或重复计量。
- 增加 VLESS TLS、VLESS 隧道、Trojan、VMess、HTTP/SOCKS/Mixed、经典 Shadowsocks 与 ShadowTLS v3 包装。分享链接在不能完整表达证书、Realm 或 ShadowTLS 包装时要求 JSON。
- DNS-01 Cloudflare、通配符与同机证书配置复用；相同 DNS-01 配置共用提供方。编辑复用源节点不会隐式修改所有复用节点的配置快照，续期由共享证书缓存负责。
- 服务器详情中的高级配置包含出站/选择组、DNS/路由、Cloudflared、Realm 服务和 WireGuard/Tailscale/OpenVPN/OpenConnect 端点；配置走原发布、预检和回滚。路由受公开节点边界约束，不替换内部链路。
- Hysteria2 Realm 节点分别保存服务端/客户端令牌，服务端令牌不进入订阅。配置服务不能证明外部服务已经可用。
- 运行时 `1.14.4-apsp.2`：固定上游补丁，认证会话标识，新增构建标签；GNU/Windows Cronet 动态库固定摘要并进入签名文件清单，macOS/musl 使用静态库，FreeBSD 不声明 Naive 出站。

- 前端 `bun run build` 通过；`bun test web/tests` 共 248 项通过。
- 浏览器：用户暂停/恢复、认证连接刷新/断开、模板保存与错误状态、逐用户限制均覆盖 1440/390/320；服务器配置编辑/保存/版本冲突保留草稿覆盖 1440/390；原节点表单和安装状态回归通过。均使用真实构建页面及本地 API 替身，没有调用生产。

- 两种制品均完成真实本地 Naive TLS 代理请求、共享 NAT 下认证主体隔离、定向断开、跨节点 TCP/UDP 合计连接上限、释放名额、无效认证拒绝及双向限速；1 MiB 在 262144 B/s 下耗时约 3.9 秒。
