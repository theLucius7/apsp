## 修改内容

- **命令面板：** 顶栏的搜索下拉改为对话框式命令面板（`control-center/CommandPalette.tsx`），取代 `GlobalSearch.tsx`。
  - 列出当前账号可见的全部页面（取自按权限过滤后的侧栏），以及收藏、最近访问和全局搜索结果。
  - Ctrl/⌘+K 打开或关闭；`/` 在输入框以外打开，在输入框内仍是普通字符；Esc 关闭。
  - 上下方向键循环选择，回车打开；Shift+回车，或底部按钮，收藏、取消收藏当前项。页面也可以收藏。
  - 按 combobox + listbox 结构标注（`aria-activedescendant`、分组名称），选项内不嵌套按钮。
  - 选择按条目标识保存：搜索结果较晚返回时，键盘选择不会跳回第一项。
- **骨架加载：** 新增 Nova `Skeleton`。`Loading` 增加 `table`、`cards`、`panel` 三种形态，用于服务器列表、代理用户、节点库、策略套餐、告警事件、延迟任务、DDNS、订阅来源、有序资源、统计、插件目录、服务器详情和阿里云页面的首次加载。公开看板首次读取时显示与服务器卡片同形的占位。
  - 占位保留 `data-slot="loading"`、`role="status"` 和屏幕阅读器文字；系统“减少动态效果”时不播放闪烁动画。
- **服务器列表：**
  - 表头复选框选择或取消当前筛选的全部服务器；部分选中时显示“混合”状态（`aria-checked="mixed"`）。
  - 批量操作（进入维护、停止接收新任务、恢复接收任务、清空选择）收进只在有选择时出现的底部操作栏。
  - 处理器、内存用量条有可读名称，75% 起显示警告色，90% 起显示危险色。服务器详情的流量用量条与看板一致，80% 起警告。
  - 离线服务器显示“最后联络 N 分钟前”，悬停显示精确时间。
  - `Progress` 修正为把当前值写入 `aria-valuenow`。复选框支持“部分选中”的显示。
- **一致性：** 15 处重复的开关设置行合并为 `SettingRow` 组件，DOM 结构不变；面板设置页的公开看板开关也改用它。
- **测试：**
  - 新增 `command-palette.mjs`：覆盖打开方式、页面过滤、方向键与循环、回车跳转与最近访问写入、搜索结果收藏、`/` 在输入框内的行为、较晚返回的搜索结果，以及手机宽度布局。
  - 新增 `server-list-selection.mjs`：覆盖全选与混合状态、批量栏、批量维护请求、用量条阈值色与名称、最后联络时间。
  - 新增 `format.test.ts`，覆盖相对时间函数 `ago`。
  - `admin-refresh.mjs`：等待中的读取完成渲染后，才推进暂停的假时钟（见下文）。

## 统一验证

环境：Bun 1.4.2（与仓库固定版本一致），Chromium 1243（Playwright 预装）。

- **构建：** `tsc -b` 与 Vite 生产构建通过，无 500 KB 警告；主入口约 246 KB（gzip 87 KB），比上一轮多约 8 KB，主要来自命令面板。
- **前端单元测试：** Bun 35 个文件、192 项通过，2469 次断言。
- **浏览器回归：** 共 53 组（52 套夹具 + 主题对比审计）。
  - 首轮 51 组通过，以下两组失败：
    - `command-palette.mjs`：测试在筛选框仍有焦点时按 `/`，面板按设计把它当作普通字符。已改为先移开焦点再按键。
    - `admin-refresh.mjs`：与上一轮整合时同一处时序断言失败，均发生在四路并行的首个批次。原因是测试在被挂起的请求发出后就推进已暂停的假时钟，此时 React 可能还没渲染“刷新中”状态，250 毫秒的提示计时器在时钟推进之后才建立，因而永远不会触发。已改为先等待保存按钮因读取挂起而禁用，再推进时钟；断言与意图不变。
  - 修复后在四路并行负载下复跑两次：`admin-refresh` 两次通过。`command-palette` 第二次暴露真实缺陷：较晚返回的搜索结果会把键盘选择重置到第一项。已改为按条目标识保存选择，并在测试中加入慢响应回归检查。
  - 冻结输入后对最终构建全量重跑：结果见下条。
- **全量重跑：** 最终构建上 53 组全部通过，合计约 1573 秒（4 路并行），无页面错误。主题对比审计覆盖登录、服务器列表、确认框和公开看板 × 浅色/暗色 × 1440/390 宽度共 16 个页面状态、1346 个可见文字节点，全部达到 WCAG AA，无横向滚动。
- **合入主线后：** 提交前主线又合入 #169（快捷入口修正、Tailwind 只扫描源码）与 #171（全局搜索结果路径）。合并后用 Bun 1.4.2 重建：`tsc -b`、Bun 192/0 通过；53 组浏览器回归全部通过（约 1556 秒），主题对比审计 1346 个文字节点均达到 AA。样式文件由约 117 KB 降至约 108 KB，原因是 #169 不再扫描已提交的旧产物。
- **仓库检查：** `git diff --check` 通过。本轮没有修改 Rust 源码，未运行 cargo。
