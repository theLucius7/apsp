## 第一步：可用性与误导性数据

### 复现的问题

- **手机无法纵向滚动（E12）：** 外框在所有宽度都是一屏高并隐藏溢出，手机分支的主列没有滚动容器，只能看到第一屏。现有夹具只检查“无横向溢出”；Playwright 点击元素时会用脚本把元素滚入视野，因此测试能通过，而滚轮和触摸滚动都无效。
- **跨断点丢草稿（E13）：** 桌面分支把主列放在分栏面板中，手机分支直接渲染主列。跨越 768px 时整棵子树被替换，打开的“添加服务器”弹窗和已填内容一起消失。代理用户等页面使用的 `ListDetailLayout` 也在断点两侧渲染不同的树。
- **离开确认的覆盖缺口（E28、E31）：** 草稿保护只拦截页面卸载和普通链接点击。命令面板直接写 `location.hash`，并且能在已打开的表单弹窗上弹出；浏览器后退、前进和代码写地址同样不经过确认。远程终端是 `role="textbox"` 的元素，不属于输入框，在其中输入“/”会打开命令面板。
- **英文状态停留在旧值（E14）：** DOM 翻译器为每个文本节点和属性记住第一次见到的中文来源。React 把“在线”改写为“离线”后，翻译器仍按旧来源写回 “Online”；切回中文时也恢复成旧文字。

### 修改内容

- **滚动归属：** 页面主列在所有宽度负责纵向滚动（`data-slot="main-scroller"`）。手机页头和菜单位于主列之上，顶栏仍在主列内吸顶，批量操作栏仍贴在可视区域底部。
- **同一棵布局树：**
  - 外框在所有宽度渲染同一个分栏组，跨断点只增删侧栏面板、分隔条和手机页头，承载页面的主面板保持挂载。
  - `ListDetailLayout` 把列表和详情通过门户渲染进稳定的承载元素，桌面分栏和手机堆叠只提供放置位置。
- **统一的离开检查（`lib/leave-guard.ts`）：**
  - 有未保存输入的表单登记离开保护（`useLeaveGuard`；`useFormDraft` 已改为调用它）。
  - 应用内链接、命令面板和 `navigate()`（原 `format.ts` 的同名函数改为转发到这里）先询问，再改地址。
  - 路由在每次 hashchange 时检查：浏览器后退、前进或代码直接写地址时询问，用户选择留下则恢复原地址，不触发第二次 hashchange；已确认的跳转不再重复询问。
  - 命令面板不在其他弹窗打开时弹出；焦点控件已处理的按键（终端发往服务器的按键）不再触发快捷键；“/”在 `role="textbox"`、`searchbox`、`combobox` 中保持为输入。
- **双语：**
  - 服务器列表和服务器详情的连接状态改在渲染处用 `t()`。
  - DOM 翻译器只在节点仍显示旧来源的译文时沿用旧来源；React 写入新值后以新值为来源，属性同样处理。
- **测试：** 新增 `shell-continuity.mjs`。
  - 390×900 下有 30 台服务器时，滚轮能滚到最后一台和页脚；勾选后批量操作栏可见；打开菜单后下方仍可滚动。
  - 打开“添加服务器”并输入后，在 390/1440/820/1440 像素宽之间切换，弹窗和输入保留；代理用户详情中的编辑弹窗跨断点保留输入。
  - 未保存的“添加服务器”弹窗打开时，Ctrl+K 与“/”不打开命令面板。代码改地址和浏览器后退都会询问；选择留下后地址恢复、输入保留，选择离开后进入目标页。
  - 网络检测的未保存方案经命令面板或侧栏链接离开时都询问，拒绝后输入保留；确认离开只询问一次。
  - 文本控件中输入“/”不打开命令面板。
  - 英文界面中服务器由在线变为离线后显示 “Offline”，不再回到 “Online”。另用一个页面外节点检查翻译器：文字和 `aria-label` 改写后按新值翻译，切回中文显示最新值。

## 第二步：交互一致性

### 复现的问题

以第一步提交 `fc7c7d1` 的产物为基线，新增的 `interaction-consistency.mjs` 七个场景全部在预期位置失败：

- **页头语言被改回（E30）：** 外观偏好的副作用依赖当前语言，在页头选择英文后重新执行，把已保存的中文写回；页头的选择也从不保存。
- **主题互相影响：** 后台把深色写在 `<html>` 上，公开看板只在自身外层元素上写浅色。颜色变量和 `dark:` 样式读取 `<html>`，从深色后台进入浅色看板后，页面背景和部分组件仍是深色。登录页、成员页同样只在部分入口设置主题。
- **关闭后焦点丢失：** 命令面板、再次验证弹窗和运维页直接使用弹窗原语，关闭后焦点落到页面开头。第四轮只给 `Modal` 与 `Confirm` 补了焦点归还；打开它们的元素被隐藏（手机布局下的桌面表格行）或移除时，焦点同样丢失。评审提到的“添加服务器”弹窗已由第四轮修复，基线复核时归还正常。
- **统计与空状态混在一起：** 统计卡片按筛选结果计数；筛选无匹配、首次读取失败都显示“从第一台服务器开始”；后台刷新失败时只在页面顶部报错，不说明列表是旧数据。
- **批量操作作用于看不见的选择（E32、E52）：** 服务器批量操作直接提交，作用于全部已选服务器，包括被筛选隐藏的；成员批量修改同样包括被搜索隐藏的成员。
- **多选只显示一行（E33）：** `NativeSelect` 固定高度并显示下拉箭头，`multiple` 列表框被压成一行。
- **手机菜单关不掉（E53）：** 注释写着 Esc 关闭，实际只有导航后关闭；Esc 和点击外部都无效。

### 修改内容

- **语言归属：** 页头的语言选择通过 `apsp:locale-chosen` 事件交给外观组件保存为管理员偏好。已保存的偏好只在首次读取和其值改变时应用，不再因当前语言变化而重新应用；设置页在页头保存后重新读取。
- **主题归属：** 新增 `lib/document-appearance.ts`。后台、公开看板、登录页、成员页和代理用户门户在显示期间各自写入 `<html>` 的主题与密度；看板外层不再单独标注主题。
- **焦点归还：** 新增 `components/ui/return-focus.ts`，由 `DialogContent` 与 `AlertDialogContent` 统一使用：记住打开时的焦点元素，关闭后归还；元素已移除或无法获得焦点时交给 `main`（后台主体已设为可聚焦）。命令面板关闭后回到按钮或按快捷键时所在的元素。
- **列表状态：**
  - 统计卡片按全部服务器计数。有筛选时标题为“筛选结果 匹配数 / 总数”。
  - 首次读取失败显示“无法读取服务器列表”和重试；没有服务器显示“从第一台服务器开始”；筛选无匹配显示“没有符合条件的服务器”和“清除筛选”。
  - 刷新失败保留上次数据，在列表上方说明可能已过期。
- **批量操作：**
  - 服务器与成员的批量操作只作用于当前可见且已勾选的对象。被隐藏的已选对象保持勾选，其数量单独说明。
  - 服务器的“进入维护”“停止接收新任务”“恢复接收任务”先确认，确认框列出服务器名称和对任务、终端、远程命令及运行时操作的影响。
- **多选控件：** `multiple` 时取消固定高度和下拉箭头，至少显示四行。
- **手机菜单：** 按 Esc 关闭；焦点在菜单内时交回“菜单”按钮；按下页头以外区域关闭。弹窗已处理的 Esc 不影响菜单。
- **测试：**
  - 新增 `interaction-consistency.mjs`，覆盖以下七类场景：
    - 页头语言保存后不被改回，新会话应用已保存的语言。
    - 深色后台 → 浅色看板 → 看板切换主题 → 回到后台，文档主题与背景各自正确。
    - 命令面板、添加服务器弹窗的焦点归还，以及打开者被隐藏时回退到 `main`。
    - 首次读取失败、重试、筛选计数、无匹配与清除筛选、刷新失败保留旧数据、空列表。
    - 手机菜单的 Esc 与外部按下。
    - 多选列表框高度。
    - 成员搜索隐藏已选成员时，批量提交只包含可见成员。
  - `server-list-selection.mjs` 改为先确认再提交，并新增被筛选隐藏的已选服务器不被修改的检查。
  - `dashboard.mjs` 与 `server-display.mjs` 改为检查文档上的主题。

## 第三步：视觉层级

### 复现的问题

以第二步提交 `9af833c` 的产物为基线：

- **筛选区占满首屏：** 服务器列表上方的筛选面板同时展开搜索、状态、分组、排序、列表分组、显示列、密度和视图保存，1440×900 下第一行服务器从 744 px 开始。390×844 的手机上第一张服务器卡片在 1144 px，首屏看不到任何服务器；每张卡片显示全部字段，高 265 px。
- **紧凑密度缩小操作目标：** 紧凑密度整体缩小间距单位，按钮、输入框、复选框和侧栏链接随之变小：按钮由 32 px 变为 28.8 px，复选框由 16 px 变为 14.4 px，侧栏链接由 36 px 变为 32.4 px。
- **代理服务排在侧栏第五组：** 与“代理网络控制平面”的定位不一致，路线图工作包 0.2 已计划调整。
- **弹窗没有关闭动画：** 共享弹窗组件的 74 处用法中，大多数调用点在关闭时直接卸载整个弹窗，内部配置的退出动画没有机会执行；自带 `open` 的编辑器关闭时同样直接返回空。基线上取消“添加服务器”后，弹窗只在 2 帧内还在文档中。
- **汇率进入 Zustand：** 看板的参考汇率作为服务端数据存在 store 中，与 ADR 0088“服务端数据不放进 store”不一致。
- **文字箭头：** 看板表格的上下行速率、“查看详情 →”、链路逐跳标题仍用文字箭头；链路编辑中的“上移/下移”按钮没有图标，与节点库的图标按钮不一致。

### 修改内容

- **服务器列表工具栏（`servers/ServerToolbar.tsx`）：**
  - 第一层是常驻一行：搜索、状态、“更多筛选”、“视图”。
  - 第二层是更多筛选（分组、新增的地区）。启用后在列表上方显示为可单独移除的条件，旁边有“清除全部筛选”；按钮上的数字表示启用了几项。
  - 第三层是视图设置：排序、列表分组、表格列或卡片字段、列表密度，以及保存、应用、恢复视图。
  - 宽屏用弹出层，手机用底部抽屉（`components/toolbar-panel.tsx`）。手机卡片字段单独设置，默认只显示处理器和内存。
  - 工具栏放进列表面板，原来独立的筛选面板删除。
- **密度：** 紧凑密度只收紧内容间距（表格行、面板内边距、区块间距）。按钮、输入框、选择框、复选框、开关、菜单项和侧栏链接保持舒适密度的尺寸；复选框和开关在触控设备上的点击区域扩大到约 40 px。
- **导航：** 代理服务移到侧栏第一组，组内依次为服务概览、代理节点、代理用户、策略与套餐、成员运营。地址不变，登录后的默认页面仍是服务器看板（待决定 D6）。
- **弹窗关闭动画：**
  - 新增 `DialogPresence`，`Modal` 与 `Confirm` 经 Motion 的 `usePresence` 关闭，退出动画结束后才离开文档。
  - 37 个文件中 78 处按条件显示的弹窗用 TypeScript 语法树批量包裹。
  - 三个自带 `open` 的编辑器在组件内部包裹；再次验证和运维确认两个直接使用原语的弹窗改为受控 `open`。
  - 关闭中的弹窗设为 `inert`，遮罩不再拦截点击。新弹窗打开时立即结束其他弹窗的退出；命令面板不把关闭中的弹窗算作已打开。
  - 关闭中的表单不再登记离开保护，避免关闭后立即导航时误报“未保存”。
  - 系统设置减少动态效果时弹窗立即关闭。
- **汇率归属：** store 只保存访客选择的币种。参考汇率由看板读取并经 context 提供，重新进入看板时用上次读取的结果过渡。
- **图标：** 看板表格的速率方向、“查看详情”、链路逐跳标题和链路编辑的上移/下移按钮改用 Lucide 图标。新增的工具栏、筛选和视图文字补充了英文词条。
- **测试：** 新增 `visual-hierarchy.mjs`，覆盖以下六类场景：
  - 桌面工具栏：首屏位置、更多筛选与条件、视图列、密度、保存视图。
  - 手机抽屉与卡片字段。
  - 两种密度下控件尺寸与内容间距。

### 第三步验证

- **构建与单元测试：** `tsc -b` 与 Vite 构建通过，无 500 KB 警告；主入口约 210 KB（gzip 73 KB）。Bun 203 项通过、0 失败，2531 次断言。
- **浏览器回归首轮（59 组）：** 44 组通过，15 组失败，全部发生在关闭弹窗之后。原因分四类：
  - **夹具：** `command-palette` 的夹具没有服务器，不再有搜索框。
  - **动画帧被页面时钟控制：** 七组夹具安装了页面时钟（无论是否暂停），Motion 的退出动画不会完成，页面一直对辅助技术隐藏。另做实验：只用浏览器合成器能处理的属性（不透明度与完整 transform）同样不会完成，因为 Motion 经动画帧结束退出。
  - **退出期间页面暂时对辅助技术隐藏：** 三组用不等待的可见性检查判断手机菜单，跳过了打开菜单。
  - **退出途中读取文字：** 第一版把关闭中的弹窗也设为 `aria-hidden`，“等待弹窗隐藏”在退出开始时就返回，随后读到仍在退出的弹窗文字，同一文字匹配到多处。
- **据此修改：**
  - 关闭中的弹窗只设 `inert`，“等待隐藏”会等到弹窗真正离开；新弹窗打开时结束其他弹窗的退出。
  - 减少动态效果时立即关闭，控制页面时钟的夹具请求减少动态效果。
  - 打开侧栏的辅助函数改为等待。
  - `shell-continuity` 另发现关闭中的表单仍登记离开保护、导致误报“未保存”，已在产品代码中修复。
