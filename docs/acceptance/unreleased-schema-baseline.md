# 未发布数据库基线收敛验收

日期：2026-11-07。决策：[ADR 0122](../adr/0122-unreleased-schema-baseline.md)。源码身份为包含本记录的提交；本轮在 `main` 完成，不部署已有环境。

## 实现范围

面板的 91 份增量 SQL 改为一份当前初始化 SQL，保留 247 张业务表和 25 个函数，增加一张结构身份表。生成时在本轮私有空 PostgreSQL 中展开旧 SQL，再导出当前 DDL；最终源码不再包含重命名、旧数据回填或历史修补过程。Agent 六份 SQL 改为一份当前结构，SQLite 版本为 2，移除 `rusqlite_migration`。两端均核对当前身份及实际结构，未知、旧版或不完整库拒绝启动，不自动重建。

移除面板启动前针对归档来源的兼容写入、页面改名别名、监控上传旧版回退、插件启用的旧节点推断。收藏中的无效页面过滤。备份脚本按实际凭据表检查密钥环，避免历史迁移编号失效。当前不同链路和来源模型的显式业务转换、外部系统导入、外部订阅协议保留；不把这些操作称为旧 APSP 数据库升级。

## 集中验证

本机 Rust/Cargo 1.99.1、Bun 1.4.4、PostgreSQL 18.6，使用已有依赖及浏览器，未升级依赖。

- TypeScript/Vite 构建与前端 248 项单元测试通过。
- 浏览器节点路由：1440/390 宽度通过，含旧页面拒绝且不静默改写、无接口写入。
- 浏览器命令面板：1440/390、1024/1100 宽度通过，含无效收藏过滤、当前访问去重、键盘与搜索。
- 面板管理脚本 12 项通过，含备份密钥环和失败保护。
- 工作区所有 target 严格 Clippy 通过；格式、架构边界、源码制品检查通过。
- 新 SQL 在隔离空库完整创建，表和函数清单与旧迁移展开结构一致（仅多结构身份表），结构指纹复查一致。
- 面板基线 7 项、Agent 基线 3 项通过；进程级检查确认空库启动和当前库重启健康，旧库启动退出码为 1 并提示手动重建。
- Agent 单元测试 301 项通过、9 项依条件忽略；工作区 dev 编译通过。
- 订阅凭据与授权重启专项 2 项、有序来源 6 项、流量汇总 3 项、诊断章节 3 项通过。全工作区运行 1584 项通过、5 项失败、28 项忽略；五项均完成单项或整组复验，合并证据为 1589 项通过、28 项依条件忽略。面板文档测试首轮因依赖制品缺失失败，单独重新构建后通过（0 个文档用例），不宣称首轮全绿。
- 首轮未提供公开测试信任根及凭据密钥环导致签名/凭据测试失败，补齐仓库 TEST_ONLY 环境后重跑。监控替身补当前设置接口；两个原升级测试显式创建当前策略组授权；两项资源测试改为验证显式停用插件不能被已有节点绕过，整组 9 项复验通过。端到端配置/流量/重启场景首轮预检拒绝，补失败检查明细后复验通过，未降低门禁。

## 限制与材料

按仓库约定不运行远端 CI。推送前 API 只读检查发现当前 fork 的工作流处于 active，因此本提交使用 `[skip ci]` 抑制 push/pull_request 自动运行；未启用、重跑或手动触发工作流。未执行真实云 API 写入、DNS、通知、生产迁移、签名 Release 或真实设备升级。Docker/PostgreSQL 16、需要真实运行时的忽略测试及各平台实机验收均不因此声明通过。旧库重建方法见[数据库基线](../database-baseline.md)。

验证后只保留本记录、测试源码及最新本地开发产物的摘要；本轮临时 PostgreSQL 已停止，编译缓存、测试日志、临时库和依赖目录已清理，删除约 15.86 GiB 逻辑数据；最新本地开发产物使用公开 TEST_ONLY 信任根，不能用于生产或正式发布。旧验收记录仍只代表当时源码与环境。
