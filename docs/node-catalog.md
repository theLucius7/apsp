# 节点库与外部订阅

“代理节点”的节点库统一管理受管直连节点、链路和已采用的外部节点。受管节点由 Agent 部署；外部节点由其提供方运行，可放进策略组供代理用户使用，或作为链路段。加入节点库不会自动授权用户。

## 导入与采用

1. 在“订阅来源”点击“添加来源”，打开导入窗口，填写来源名称，粘贴 HTTPS 订阅地址或节点内容，也可上传配置文件。支持已有解析器接受的分享链接、Base64 链接集合、sing-box JSON 和 Clash 节点配置，内容上限为 2 MiB。
2. 点击“解析并预览”，查看协议、地址及不支持原因，勾选需要的节点。此时还未创建正式来源或节点；预览十分钟内有效。
3. 点击“加入节点库”提交。提交使用刚才预览的同一份内容，不再次抓取订阅；未选节点保留在来源记录中，可稍后采用。

来源只提取支持的具体节点，不导入其路由、DNS、脚本或其他运行配置，也不提供 Clash 订阅输出。URL、请求凭据和节点秘密不会出现在预览列表中。

来源详情可采用或取消采用节点。取消采用、删除前会检查代理用户授权和链路引用；有引用时先解除引用。删除后不会因来源刷新自动回到节点库，需显式重新采用。

## 来源更新与流量

URL 来源支持手动刷新、自动刷新开关和刷新间隔；关闭自动刷新会保留已设置的间隔。可按提供方要求设置请求凭据与有限的 User-Agent。内联来源通过重新提交内容更新。

刷新会显示新增、更新、缺失和不支持的数量。已采用节点按同一来源内的稳定身份更新，保留本地别名、标签、备注及排序；新发现的节点需另行采用。失败时保留上次成功内容并标记旧数据，更换来源身份则需重新确认节点与授权。

流量、额度及到期时间来自提供方的 `Subscription-Userinfo` 响应头，仅作参考。缺少字段显示“未知”；只有上传和下载均已知时才计算已用流量。抓取失败不清零缓存，不把上游流量写入服务器网卡或代理用户计量账本。

## 整理与批量操作

可按名称、地址、标签和备注搜索，并按类型、协议、状态、服务器或来源筛选。支持本地别名、标签、备注、自定义排序，以及批量改名、标签调整、启用、停用和删除。

选择本页与选择筛选结果是不同范围，单次批量操作最多 200 项。提交会核对每项的当前修订（CAS）：其他操作已修改其中任何一项时，整个批次不生效，刷新后重新确认。来源节点的采用操作同时核对来源、节点版本及管理修订号，防止旧选择作用于新内容或恢复已删除节点。重新采用需读取当前状态并明确确认。

受管节点启停仍需等待设备应用。外部节点启停控制后续订阅分发，不会启停提供方的服务，也不会改写已保存的链路配置。

## 放进策略组

代理用户只经策略组获得资源（[ADR 0112](adr/0112-group-only-access.md)，原来按人分配外部节点的做法已删除）。在「策略与套餐」中把已采用且启用的外部节点加入策略组，并指定更新方式：

| 方式 | 后续来源刷新 |
| --- | --- |
| 跟随节点 | 使用同一节点身份的新版本，不自动改指向另一个来源身份。 |
| 固定版本 | 保留选定的不可变配置版本，不随参数更新切换。 |

固定版本仍受所在策略组和来源状态约束。来源被归档、删除或更换身份，节点缺失、身份歧义、停用或取消采用后，不再向后续订阅提供该节点。普通刷新失败可继续使用最后可信版本，并显示来源错误。

策略组成员获取 **sing-box 完整 JSON 订阅**，其中组合用户有效的受管节点与外部节点。包含外部节点时不再使用分享链接集合，避免静默遗漏节点；旧有无外部授权的分享链接保持兼容。用户套餐的订阅准入条件仍适用。

外部节点使用提供方凭据，不生成受管节点的用户独立凭据，也不下发到 Agent。把节点移出策略组或停用节点只影响之后获取的订阅；已下载的外部凭据须由提供方撤销。面板不能据此统计或强制执行提供方的流量额度。

## 升级兼容与诊断边界

升级前已有外部节点迁移为已采用，保留可见性，但不会自动授权代理用户。旧用户、订阅令牌、受管节点凭据、历史流量及已有链路版本保留；旧链路选点不额外要求先加入节点库。

数字编号来源已于 2026-11-04 迁入有序来源，2026-11-09 删除（ADR 0131）：节点编号、版本编号、采用状态、管理设置和已有授权保持不变，用户订阅内容不变。

导入成功表示配置通过当前解析和校验，不代表真实代理可连接或吞吐达标。本轮未新增独立测速运行时；诊断仍遵循共用任务的资源预算、取消与历史管理，以及现有实机验收要求。

架构与兼容约束见 [ADR 0076](adr/0076-node-catalog-and-external-access.md)。
