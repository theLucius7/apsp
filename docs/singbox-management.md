# 代理管理与高级配置

构建工具的内核基线为 `1.14.4-apsp.2`；面板在它签名发布并导入前仍下发 `1.14.4-apsp.1`（切换顺序见[签名发布](release.md)），依赖新内核的连接管理、Naive 出站与新增端点在切换后才可用。单台服务器仍只运行一个受管 sing-box。下面入口沿用服务器、代理节点与代理用户页面，见 ADR 0129。

## 用户与连接

在代理用户的诊断与配置区域暂停或恢复用户。暂停保留身份、授权和流量账本，订阅立即按暂停资格处理；受管节点需要服务器应用新配置后才停止授权。离线设备不能立刻收到变更。外部订阅提供方的已下载凭据不能由 APSP 停用。

连接区域按服务器刷新认证连接。第一次查询只显示计数，两次有效采样之间可显示速率。来源地址不用于判断用户，多个用户共用同一 IP 仍独立列出。可断开选中连接，或每批断开最多 256 条；列表截断时需再次刷新。配置变化、旧采样或设备离线时不执行过期操作。用户限速与连接上限按每台服务器全部受管节点合计，零表示关闭。

## 节点与证书

创建节点时可选 VLESS Reality/TLS/隧道、Trojan、VMess、HTTP、SOCKS、Mixed、Shadowsocks/2022、ShadowTLS v3、Hysteria2、TUIC、AnyTLS、Naive、Snell v6。ShadowTLS 使用内部 Shadowsocks 入站，计量只做一次。VLESS 隧道作为 Cloudflared 源站时需要监听本机回环地址。

节点高级字段的多个公开地址用于生成不同客户端连接入口，不新增服务端端口。每项填名称、主机与端口，可选 SNI 和 HTTP Host；例如 IPv4、IPv6 或不同域名。显示多个地址不会重复统计流量。

TLS 可以上传证书、用 HTTP-01 自动签发，或用 Cloudflare DNS-01 签发通配符证书。DNS API 令牌只向持有证书的受管服务器分发；保存空令牌沿用原值。复用证书时选择同一服务器的源节点，保存的是配置快照；相同 DNS-01 配置共用证书提供方与续期缓存。修改源节点不会隐式改写其他节点快照。

Hysteria2 Realm 分别填写服务端和客户端令牌。订阅只包含客户端令牌。无法完整表达证书信任、Realm 或 ShadowTLS 包装的分享链接会要求改用 JSON，不省略必要参数。

## 客户端模板

代理用户的高级模板可分别配置 sing-box 和 Clash Meta。示例包含名称筛选分组、自动测速、DNS 与分流；sing-box 还支持内联/HTTPS 规则集，Clash 可使用测速与故障切换组。分组只能使用此用户当前有权接收的节点；引用缺失、空组、循环或格式错误会明确失败。名称筛选可用于地区分组，`*` 匹配全部节点。

模板版本统一为 sing-box 1.14.4。模板不会扩大授权，也不改变服务端路由。Clash 对不能等价表达的协议仍给出说明。

## 服务端配置

服务器详情的代理业务区域提供服务端 JSON 配置及示例，包含 `outbounds`、`endpoints`、`services`、`cloudflared`、`dns` 和 `route`。自定义标签使用 `extra-` 前缀，出口与端点可被路由引用。路由只作用于受管公开节点，已有链路内部配置、计量、用户限制和控制接口不能被覆盖；不能引用任意文件、命令或系统接口。

支持 Naive 出口、Cloudflared 隧道、Realm 服务，以及 WireGuard、Tailscale、OpenVPN 客户端、OpenConnect 用户空间端点。Cloudflared 必须引用本机回环 VLESS 隧道节点。使用真实服务前先填写地址、认证及证书；保存通过编译后仍须部署预检，Agent 原生检查失败时保留已应用配置。

凭据读取为 `__APSP_REDACTED__`，保留此占位符即沿用原值。对象重排按标签或名称保留凭据；新对象必须填真实值。版本冲突不会自动覆盖其他编辑，编辑区保留草稿，重新载入前自行保存需要保留的内容。

Naive 出口依赖随签名制品提供的 Cronet。使用包含该附件的新制品前须升级到声明版本化运行时附件能力的当前 Agent；预检与清单下发均会拦截旧 Agent。Linux glibc 要求 2.31 及以上；Windows 随包提供 DLL，macOS 与 musl 使用静态构建，FreeBSD 不提供该出口。各平台与真实外部服务的验收状态见[本轮验收记录](acceptance/sui-capabilities-20261107.md)。
