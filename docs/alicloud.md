# 阿里云 CDT、ECS 启停与公网带宽插件

插件在面板执行，入口为侧栏「扩展 → 阿里云 CDT」，也可从「插件中心 → 插件目录」的阿里云条目进入。账号和资源独立登记，不需要 Agent，不更改服务器网卡或代理用户的计量账本。

## 接入

1. 添加云账号，选择中国站或国际站；站点决定 BSS 账单端点，与资源地域不同。填写 RAM 访问密钥对，默认启用查询，默认关闭自动控制。
2. 登记资源名称、地域、ECS 实例 ID 或 EIP 分配 ID。带宽管理支持已有固定公网 IPv4 的 ECS 和按量付费的独立 EIP；共享带宽包、包年包月 EIP 不做变配，绑定 EIP 的带宽应单独登记 EIP。ECS 启停按实例身份独立查询，节省停机后公网 IP 消失不影响启停状态核对；EIP 没有启停功能。
3. 查询当前配置，核对公网 IP、带宽和公网计费方式。账号每五分钟查询账单与兼容用量，每轮轮换核对最多八个资源；手动账号刷新有一分钟冷却。最多八个云账号、全局三十二个云资源。

凭据不回显，编辑时两项同时留空保留，同时填写替换。只存在面板数据库，数据库备份包含明文云密钥；当前没有额外字段加密。移除账号必须先移除资源登记，随后清除密钥；移除登记不会删除云资源。

所需接口按功能授予，RAM 授权名称、资源范围与条件请依各接口官方映射配置：

| 功能 | 接口 |
| --- | --- |
| CDT 兼容用量，只读 | `ListCdtInternetTraffic` |
| CDT 账单，只读 | `QueryInstanceBill`，产品 `cdt` |
| 账号可用额度、实例账单 | `QueryAccountBalance`、`DescribeInstanceBill` |
| ECS 固定公网配置 | `DescribeInstances`、`ModifyInstanceNetworkSpec` |
| ECS 开机与停机 | `StartInstance`、`StopInstance` |
| 独立 EIP 配置 | `DescribeEipAddresses`、`ModifyEipAddressAttribute` |

不需要创建/释放 IP 或绑定资源权限。仅查询时不必授予变配或启停权限；使用启停策略时按已登记实例授予相应权限。密钥应使用最小资源范围，不能只依赖面板筛选来限制云端权限。

## 用量和费用

参考用户指定的 [CDT-Monitor](https://github.com/wang4386/CDT-Monitor) 实现兼容用量查询：`cn-` 地域（排除中国香港）计入中国内地，其他地域计入海外，1 GB 按 1024³ 字节显示。接口没有完整公开契约，响应无可信账期字段；页面显示获取时间而不伪造云端统计截止时间。失败保留旧读数和错误，不显示为最新成功数据。

账单使用官方 BSS 接口，按北京时间当月完整分页（最多一千项）读取，展示原用量、单位、费用和币种。兼容用量不等于账单，账单不等于实时流量；CDT 项目可能含公网及跨地域传输。当前不混加不同币种，也不计算免费额度余额。空账单不证明没有流量或未开通。

CDT 开通状态、套餐/免费额度与升级请在 [CDT 控制台](https://cdt.console.aliyun.com/) 核对；目前没有已确认的公开开通/关闭接口。开通会涉及阿里云产品及计费规则，插件不代替控制台开通。

## 手动调整

「调整带宽与计费」先查询云资源，产生五分钟有效的预览。确认界面显示原配置、目标配置、公网 IP，以及可能产生费用；勾选确认后才入队执行，授权该次变配及云端可能产生的扣款。范围为 1–100 Mbps。

- ECS 支持公网出带宽和 `PayByTraffic` / `PayByBandwidth` 转换，保持原 IP，不自动申请 IP。
- 独立 EIP 公开接口仅调整带宽，计费转换从界面进入 [EIP 控制台](https://vpc.console.aliyun.com/)；控制台改动后先刷新。
- 执行前再次核对本地版本和云资源原状态；任一变化使旧预览或操作失效。未开始的操作可取消。
- 操作先持久化再提交。超时、重启、未知回执之后只读回状态，不自动重发变配，也不把 HTTP 接收等同成功；核对到目标配置才标记完成。
- 结果待核对时阻止该资源新变配。先到云控制台确认资源与订单，必要时点「已人工核对」结束跟踪；此操作不撤销云端请求，会暂停该资源的自动策略。

云 API 与数据库不共享事务；云端超时仍可能稍后生效，不能承诺取消尚未确认的云请求。操作历史保留 180 天，页面优先展示未完成及最近一百条。

## 自动流控

账号策略与资源策略都默认关闭，必须分别启用。设置账号「当月已出账 CDT 流量阈值」和每个资源的目标带宽。阈值是账号全部 CDT 账单项目的合计，不是某一资源用量，也不是阿里云剩余免费额度。

仅当完整当月账单全部是明确的后付账单 `PayAsYouGoBill`、具有实例身份且使用 `GB` 单位、最近十五分钟成功读取并达到阈值时，才对明确纳入的、当前按流量计费且高于目标带宽的资源生成降速操作。退款、调账、预付订单、缺少账单类型或实例身份的记录仍可查看，但不能参与自动控制；空账单、不支持的单位、分页缺失、查询失败、数据过期或跨月不触发。重复账单维度即使用量、金额或显示元数据变化，也视为分页不稳定而拒绝合计。此降速策略不自动换计费方式、增加带宽或按月恢复；停机另在 ECS「配置自动启停」中明确启用。兼容 CDT 用量读数不会单独触发变配或启停。

每个资源在同一账号版本、资源版本和账期内最多触发一次；失败不会无限重试。核对后重新保存策略可允许再次判断。编辑或停用会取消尚未开始的旧操作；正在执行的请求结束后才能确认停用。 已发送或结果待核对的带宽/启停任务存在时，不允许更换账号站点及密钥；先读回核对或明确结束跟踪。结束未确认的带宽跟踪会同时关闭该资源的自动降速与自动启停，并保留手动暂停，避免下一轮立即再执行。最低 1 Mbps 仍会产生流量和费用，账单有延迟，应留出阈值余量；此功能不提供实时费用封顶。

## ECS 手动与自动启停

资源卡片提供「开机」「停机」「配置自动启停」。手动操作先读取云状态，展示实例、地域、动作和五分钟有效期；确认后返回持久任务，页面每五秒读取本地快照。操作与带宽变配互斥，同一资源有未核对任务时不能再次执行。预览与排队任务可取消，已经发送的请求不能撤回。

| 停机模式 | 行为 |
| --- | --- |
| 普通停机 `KeepCharging` | 正常关机，继续收费并保留计算资源；不强制断电。 |
| 节省停机 `StopCharging` | 面板先要求按量付费 VPC 实例；计算资源可能被回收，磁盘/EIP 等仍可能收费，固定公网 IP 可能变化，开机依赖库存。 |

阿里云对不支持节省停机的实例可能降级为普通停机。面板必须核对实际 `StoppedMode`；模式不符显示「实例已停止，但停机模式与请求不符」，缺少模式则保持待核对，不把停机成功等同于免费。不会为切换已停止实例的模式自动执行先开后关，也不会初始化本地磁盘。详见 [官方节省停机说明](https://www.alibabacloud.com/help/zh/ecs/user-guide/economical-mode)。

自动启停默认关闭，每个 ECS 分别配置：

- **流量阈值**：账号 CDT 月额度 GB × 触发百分比，可选「仅通知」或「停机并通知」。使用完整当月账单合计，与按资源计费的账单缓存不同。账单存在延迟，建议预留额度；不提供实时流量硬限额。停止保护优先于开机，生效后持久化；过期/失败账单不能解除保护，新的完整且低于阈值的账单才解除。新月份也需成功取到账单后才能开机；空账单不擅自当作零。
- **每日计划**：开机和停机时间必须不同，支持如 23:58–08:00 的跨午夜时段。默认北京时间 `UTC+08:00`，允许配置固定 UTC 偏移，不自动处理夏令时。只补执行最近十分钟内的事件，数据库持久去重，面板重启不重复执行同一天的同一计划。停机时段不会因相邻开机事件的补偿窗口再次开机。
- **抢占式保活**：只启动仍存在、状态为已停止的抢占式实例；服从阈值、手动暂停和计划允许运行时段。云端明确拒绝（例如库存不足）后至少等待十五分钟才创建新尝试；请求超时/未知回执保持待核对，只读回，不重发。已释放的实例不能恢复，不自动创建、竞价换规格或购买新实例。
- **手动暂停**：确认手动停机即持久暂停计划开机和保活，即使取消该排队任务也不自动解除。手动开机或「恢复自动开机」明确解除；流量停机保护仍有效。结束不确定启停任务的跟踪会暂停自动启停和降速，管理员须先核对云端。

启停状态通常每分钟查询；每轮最多处理八个已领取任务和四个资源，失败按云端退避。每次写入前持久化意图；崩溃恢复只读状态。阈值持续超限时若实例又被外部开机，可在至少十五分钟的尝试间隔后再次停机。日程不是补跑历史命令，也不保证云端一定能按时成功启动。

计划和保活由面板后台执行，面板必须在目标实例停机期间保持在线；不要依赖部署在该实例自身的面板为自己定时开机。

## 账单、余额缓存和通知

- 账号的可用额度由 `QueryAccountBalance` 提供，保留原币种与十进制金额，不等同现金余额或免费流量。实例月账单通过 `DescribeInstanceBill` 按实例 ID 完整分页（最多一千项），保留每项金额及币种，不把不同币种混加。
- 余额、实例账单缓存六小时，实例账单跨月失效；失败保留旧值、旧查询时间和错误，按至少五分钟退避，不显示虚假的零。CDT 控制账单独立保持五分钟查询、十五分钟有效期，不因费用缓存延迟控制判定。
- 浏览器刷新只读数据库。「请求更新」安排后台更新并受冷却/错误退避限制；不会因多个浏览器标签反复请求云账单。更换账号或凭据会清空相应缓存，防止串用旧账号数据。
- 「云资源通知」记录阈值和启停结果，保留一百八十天。通过「告警设置」配置的 Telegram/Webhook 分渠道投递、独立重试；没有启用渠道时仍保留站内事件。云通知使用独立插件队列，投递状态在此页查看，不混入服务器离线告警计数。阈值通知按资源配置版本和月份去重，任务结果按任务与状态去重。

## 验证范围

实现及参考接口见 [ADR 0057](adr/0057-alicloud-cdt-management.md)、[ADR 0058](adr/0058-alicloud-power-and-billing-cache.md)。开发测试只使用回环云接口替身和临时 PostgreSQL，不提交真实 DNS、开通、变配、启停、扣费或通知。

真实验收须另行在专用云账号/测试资源授权：先核对 RAM 权限和读数，再分别验证 ECS/EIP 预览、单次调整与读回、超时核对及停止策略。CDT 兼容接口的可用性、中国站/国际站差异、云端订单限制、真实出账延迟均未实机验收。CI 保持暂停，不据本地测试宣称线上全绿。

启停验收还须覆盖两种停机模式及降级、节省停机后的公网 IP 变化、库存不足、抢占中断/释放、跨午夜计划、阈值与人工停机冲突、真实余额/账单分页和通知投递。源码与本地替身通过不代表这些真实云能力已签收。

## 原 CDT 脚本迁移

需要保留账号 BGP 额度池、月度最高用量、突增缓冲和低用量自动开机时，使用新增的「CDT 脚本守护」模式。详见 [行为与迁移步骤](cdt-script-migration.md) 和 [ADR 0093](adr/0093-cdt-script-guard.md)。
