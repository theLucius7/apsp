# 服务器资产与流量额度

后台“服务器”的新增与编辑共用资产字段，详情页“资产与流量额度”也可进入编辑。弹窗顶部分区按钮可直接跳到地区标签、成本到期、流量额度、监控或拨测。保存失败保留输入；名称、资产以及创建时的采样/拨测设置一起校验和保存。

## 地区与标签

- 地区为手动填写的代码，最多 16 字；例如 `JP`。不根据 IP 擅自推断。
- 展示分组最多 40 字；标签用中英文逗号分隔，去除重复，最多 16 个，每个最多 32 字。
- 展示页支持地区、分组筛选，并把标签纳入搜索。隐藏会排除看板列表、详情与历史，后台仍保留设备。看板默认要求登录，可通过独立开关开放未隐藏设备的只读展示。

## 成本与到期

- 金额每个费用周期最多两位小数，留空表示未知，`0` 表示免费。币种使用三位字母代码，默认 CNY，不自动兑换或混合汇总不同币种。
- 费用周期为 0–3650 天；0 是一次性费用。常用 30、90、180、365 天，也可自定义。
- 到期日期使用所选日期的 UTC 零点。详情与展示页分别标明未设置、即将到期及已到期；到期不触发停机。
- “自动顺延到期记录”需要日期和非零周期。到期后沿原边界按周期跳到下一个未来日期，面板重启或错过多期会一次追平；不会替供应商扣款。读取即时投影，后台维护任务在 30 秒周期内持久化；并发修改使用原值比较，避免覆盖管理员编辑。

## 流量额度

- 支持上下行合计、较大值、较小值、仅上行、仅下行。额度为 0 表示不限制；超额只提示，不停止 Agent、代理或网络服务。
- 每月 UTC 重置日为 1–31；短月取最后一天。例如 31 日重置在闰年二月使用 29 日，下期仍为 3 月 31 日。此周期独立于费用周期和代理账本 epoch。
- GB/TB 为十进制单位，GiB/TiB 为二进制单位。面板请求、存储和响应使用精确的十进制字符串，支持至 `18446744073709551615` 字节。编辑不会通过 JavaScript Number 转换丢失低位。
- 统计网卡留空时包含所有上报网卡；支持 `*` 与 `!` 排除，逗号分隔，排除优先。例如 `eth*,!eth1`。请按设备实际接口选择出口网卡，避免虚拟和回环接口重复统计；选项只影响汇总，不改变 Agent 采集。

服务器使用带时间戳的已有遥测维护逐网卡累计。第一个完整采样建立基线，后续差值按 UTC 日归集；本期始于首个被观测到的采样，不把接入前的全部系统计数归入本期。每次遥测的检查点、日用量与确认记录在同一个事务内完成，网络重放不会重复累加。同批按时间排序，晚到的旧数据不回退检查点；新网卡、缺少任一方向计数时重新建立基线。任一方向计数回退时，该方向按新计数记录；系统运行时长明确减少时按可确认的重启处理，记入新计数，均标记不完整。采样墙钟前进与系统运行时长不一致时，只标记不完整；单调计数仍取可确认的差值，不能把校时当成重启再累计启动以来的总量。

差值归入后一个采样所在日，跨日断连可能影响额度周期归属；超过五分钟的采样断档、接口变化、墙钟与运行时长不一致或计数重置都会保留不完整标记。旧无采样时间的消息仍可显示指标，但不参与本周期计量。原始日记录保留，所以修改重置日、口径、额度或网卡选择后可重新汇总。面板升级之前、计数清零前未采集的数据及无法识别的重启不能补算；本功能是观测用量，不能替代运营商账单。

## 验证与升级

新增 `0017_server_assets.sql`，面板启动时随既有迁移执行。旧服务器默认没有资产信息、没有额度，现有名字、身份、节点和代理账本不变。先按既有部署流程备份数据库，再更新面板；现有支持带时间戳遥测的 Agent 无需增加配置项。

本地测试包含金额/字节精度、认证与原子保存、自动顺延、UTC/月末/闰年、重放/乱序、缺失/新网卡/重启、大整数、存储故障回滚和桌面/手机操作。专用测试机仍需核对真实出口网卡、接入基线、断连与跨日用量，并与供应商账单比较；不把夹具结果视为生产验收。相关决策见 [ADR 0036](adr/0036-server-assets-and-traffic.md)。

## 展示、更新与离线通知

新增和编辑服务器都可切换「在展示页隐藏」「离线告警」及「自动更新 Agent」，并填写「Agent 下载加速」。隐藏节点在看板列表、详情、资源历史和拨测历史中统一不可见；后台服务器详情仍可管理。自动续费继续只顺延到期记录，不执行付款。

「面板设置」可开启公开看板，默认仍要求登录。公开模式不包含主机名、公网地址、设备凭据、成本和通知/镜像设置，管理接口始终需要管理员会话。公开访问被关闭或节点被隐藏后，后续请求拒绝读取，前端清除被拒绝的快照。

Agent 默认直接从 GitHub Release 下载；镜像示例 `https://mirror.example.com` 会请求 `https://mirror.example.com/https://github.com/…`，支持镜像自身或 GitHub 官方下载域的 HTTPS 重定向，不向镜像发送设备凭据。注册和运行配置仍使用面板。自动更新只选择面板已导入且与当前 ABI、协议兼容的较新稳定签名版本。

离线告警默认开启，阈值默认 5 分钟，可设为 2–1440 分钟。服务器至少上报过一次才纳入，面板重启后的宽限期与阈值一致。站内「告警事件」展示事件、恢复时间和 Telegram 发送情况。设置机器人令牌和会话 ID 后可启用 Telegram；读取不会返回令牌，空输入保留，勾选清除可删除。修改机器人、接收会话、话题或关闭通知会取消等待发送的旧消息，不将旧事件发送给新接收方。发送失败按退避重试，最多 8 次；网络中断时可能无法判断 Telegram 是否已接收，通知携带事件编号供辨认。接口行为参考 [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage)。

## 矫正本期流量

在服务器详情的「资产与流量额度」点击「流量矫正」，填写打开窗口时应有的本期上传/下载流量、单位和原因。使用字节单位可以完整保留大整数；GB/TB 为十进制，GiB/TiB 为二进制。

矫正保存独立调整记录，原始遥测、网卡计数和日累计不变，保存期间新增的采样继续累加。若另一个管理员窗口已矫正，或周期/网卡选择发生变化，本次保存会拒绝，需刷新后重新填写。下个 UTC 账单周期自动不再应用；修改重置日或网卡范围会作废旧矫正。改变上/下行统计口径仍使用已矫正的双向值。该功能不更改代理用户流量账本、不重置计量 epoch，也不能补回未观测流量。

统一延迟任务，以及资源超限、到期、流量额度提醒和 Telegram 模板/话题/测试消息，见[延迟检测与通知](monitoring.md)。新到期、流量提醒默认关闭，不预设资源规则；原离线告警配置继续生效。
